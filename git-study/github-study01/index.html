PEP 8 — 파이썬 코드 컨벤션

파이썬 코드의 가독성과 일관성을 위한 공식 가이드라인입니다.

인덴테이션 (들여쓰기)

4칸 스페이스를 사용합니다. 탭을 사용하지 마세요.

# ✅ 좋은 예시
def mean(values):
    total = sum(values)
    return total / len(values)

Optional 사용법

Optional[T]는 T | None을 의미합니다. 기본값이 없을 때 사용합니다.

pyproject.toml — 현대적 프로젝트 설정

pyproject.toml 예시

[project]
name = "my-ml-project"
version = "0.1.0"
description = "AI 분석을 위한 머신러닝 프로젝트"
requires-python = ">=3.12"
dependencies = [
    "pandas>=2.2.0",
    "numpy>=1.26.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=8.0.0",
    "ruff>=0.4.0",
]

pyproject.toml 사용법

# 의존성 추가
uv add pandas
uv add "pandas==2.2.0"  # 특정 버전

# dev 의존성 추가
uv add --dev pytest ruff

# 의존성 제거
uv remove pandas

# 프로젝트 트리 확인
uv tree

# lock 파일 생성
uv lock

uv — 빠른 패키지 관리자

pip보다 uv가 훨씬 빠릅니다 (Rust 기반).

주요 명령어

# 가상환경 생성
uv venv
uv venv myenv
uv venv --python 3.12

# 패키지 설치
uv pip install pandas numpy
uv pip list

# 가상환경 없이 바로 실행
uv run python main.py

# 프로젝트 초기화
uv init
uv init my-project

# 의존성 동기화
uv sync

코드 컨벤션 체크리스트

  • 인덴테이션은 4칸 스페이스
  • 한 줄 길이는 79자 이하
  • 함수는 snake_case, 클래스는 PascalCase
  • 상수는 ALL_CAPS
  • import 순서: 표준 → 서드파티 → 로컬
  • 타입 힌트는 모든 함수에 명시

왜 코드 컨벤션이 중요한가?

  1. 가독성: 새 멤버도 쉽게 이해할 수 있음
  2. 자동화 도구 통합: Black, Ruff와 완벽 호환
  3. 팀 협업: 코드가 같은 스타일이면 리뷰 효율이 올라감
