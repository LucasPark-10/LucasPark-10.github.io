[머신러닝 분류 모델] SVM과 커널 - 결정경계를 찾기

2026년 8월 10일 월요일

SVM → Margin → Support Vector → Soft Margin → Kernel Trick의 흐름

1. SVM이란?

SVM(Support Vector Machine)은 분류 문제에서 클래스를 가장 잘 나누는 결정경계를 찾는 모델입니다.

단순히 데이터를 나누는 선 하나를 찾는 것이 목적이 아니다.

각 클래스와 결정경계 사이의 Margin을 최대화하는 경계를 찾습니다.

● ● ●        ○ ○ ○
● ● ●        ○ ○ ○
● ● ●        ○ ○ ○
       │
       │ 결정경계
       │

2. Margin

결정경계와 각 클래스의 가장 가까운 데이터 사이의 거리를 생각하면 됩니다.

SVM은 이 Margin을 최대화하려고 합니다.

수학적으로는

\[ \|w\|^2 \]

를 최소화하는 문제로 표현할 수 있습니다.

즉,

Margin 최대화 ↔ \(\|w\|^2\) 최소화

라는 관계가 중요합니다.

3. Support Vector

결정경계에 가장 가까운 데이터들이 있습니다.

이 데이터들이 Support Vector다.

Support Vector가 중요한 이유는 결정경계가 이 데이터들의 위치에 크게 영향을 받기 때문입니다.

4. Soft Margin

현실 데이터는 완벽하게 분리되지 않는 경우가 많다.

따라서 일부 데이터가 Margin을 침범하거나 잘못 분류되는 것을 허용합니다.

이를 위해 Slack Variable \(\xi\)를 사용합니다.

그리고 오차를 얼마나 강하게 처벌할지 결정하는 파라미터가 C다.

C가 큰 경우

  • 오차를 강하게 처벌
  • Margin 침범을 적게 허용
  • 훈련 데이터에 더 엄격
  • 과적합 가능성 증가

C가 작은 경우

  • 오차를 어느 정도 허용
  • 더 넓은 Margin을 선택할 가능성
  • 일반화에 유리할 수 있음

암기

C ↑ → 오차 허용 ↓

5. Kernel SVM

SVM은 선형으로 분리할 수 없는 데이터에서는 한계가 있습니다.

대표적으로 XOR 형태가 있습니다.

○       ●

●       ○

2차원 평면에서 직선 하나로 완벽하게 분리하기 어렵습니다.

6. 고차원 공간으로 이동

데이터를 새로운 공간으로 변환한다고 생각할 수 있습니다.

\[ x\rightarrow\phi(x) \]

그러면 원래 공간에서는 복잡했던 데이터가 새로운 공간에서는 선형적으로 분리될 수 있습니다.

문제는 실제로 고차원 변환을 수행하면 계산량이 매우 커질 수 있다는 것입니다.

7. Kernel Trick

그래서 직접 변환하지 않고 다음 값을 계산합니다.

\[ K(x_i,x_j) = \phi(x_i)^T\phi(x_j) \]

이것이 Kernel Trick입니다.

대표적인 Kernel은 다음과 같습니다.

Linear

\[ K(x_1,x_2)=x_1^Tx_2 \]

Polynomial

\[ K(x_1,x_2) = (\gamma x_1^Tx_2+\theta)^d \]

RBF

\[ K(x_1,x_2) = \exp(-\gamma\|x_1-x_2\|^2) \]

Sigmoid

\[ K(x_1,x_2) = \tanh(\gamma x_1^Tx_2+\theta) \]

8. RBF Kernel과 Gamma

RBF Kernel에서는 Gamma가 매우 중요합니다.

\[ K(x_1,x_2) = e^{-\gamma\|x_1-x_2\|^2} \]

Gamma ↑

  • 가까운 데이터에 민감
  • 결정경계가 복잡해짐
  • 과적합 가능성 증가

Gamma ↓

  • 더 넓은 범위의 데이터를 비슷하게 봄
  • 결정경계가 부드러워짐
  • 과소적합 가능성 증가

9. SVM 전체 정리 

SVM
 ↓
Margin 최대화
 ↓
Support Vector
 ↓
선형 분리의 한계
 ↓
Kernel Trick
 ↓
비선형 결정경계

핵심 암기

SVM = Margin 최대화

C ↑ = 오차 허용 ↓

Kernel = 비선형 문제를 다루기 위한 방법

RBF에서 Gamma ↑ = 결정경계 복잡도 ↑

한 문장 정리

SVM은 Margin을 최대화하는 결정경계를 찾고, Kernel Trick을 사용하면 선형으로 분리하기 어려운 데이터에도 적용할 수 있습니다.
