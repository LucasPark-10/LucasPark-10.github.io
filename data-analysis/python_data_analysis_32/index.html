[PyTorch] PyTorch 모델 구현과 최적화

2026년 8월 4일 화요일

들어가며

이번 글에서는 PyTorch를 활용해 딥러닝 모델을 구현하고, 손실 함수와 최적화 함수를 통해 모델을 학습시키는 과정을 정리해보겠습니다.

1. PyTorch 주요 키워드

PyTorch로 딥러닝 모델을 만들고 학습시키기까지의 전체 흐름은 다음과 같은 키워드로 요약할 수 있습니다.

Datasets → DataLoaders → torch.nn → 손실 함수 → 모델 학습

torch.nn

  • 딥러닝 모델을 구성하기 위한 여러 레이어가 구현되어 있는 공간입니다.
  • torch.nn에 있는 다양한 레이어를 활용해 딥러닝 모델을 구현할 수 있습니다.
  • TensorFlow와 비슷하게 Sequential 모델을 활용하여 구현할 수 있습니다.

2. PyTorch Sequential Model

PyTorch도 TensorFlow와 유사하게 Sequential 모델을 활용하여, 레이어를 차례로 나열하는 것만으로도 모델을 구현할 수 있습니다.

전체적인 개발 흐름은 다음과 같습니다.

데이터 탐색 → 데이터 전처리 → 모델 정의 → 학습 → 평가 → 성능 개선

모델 구현 예시 

import torch.nn as nn

model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(28 * 28, 128),
    nn.ReLU(),
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Linear(64, 10),
    nn.Softmax(dim=1)
)

구현 순서

  1. PyTorch의 Sequential 모델을 생성하고, 원하는 레이어를 일렬로 나열합니다.
    • 이때 레이어의 형태(입력·출력 차원 등)를 지정해줍니다.
    • 활성화 함수는 별개의 레이어로 추가할 수 있습니다.
    • TensorFlow와 달리, 별도로 컴파일을 적용하지는 않습니다.

같은 모델 구조를 아래와 같이 append()를 사용해 생성할 수도 있습니다.

model = nn.Sequential()

model.append(nn.Flatten())
model.append(nn.Linear(28 * 28, 128))
model.append(nn.ReLU())
model.append(nn.Linear(128, 64))
model.append(nn.ReLU())
model.append(nn.Linear(64, 10))
model.append(nn.Softmax(dim=1))

PyTorch Linear Layer

nn.Linear(28 * 28, 128)을 예로 살펴보면 다음과 같습니다.

  • 입력: 28 × 28 = 784
  • 출력: 128
  • 가중치 Tensor의 차원: (784, 128)

PyTorch의 Linear Layer는 입력 크기(차원)와 출력 크기(차원)를 모두 설정해주어야 합니다.

3. nn.Module 기반 모델 구현

TensorFlow의 Functional API처럼, 레이어를 일렬로 나열하는 것만으로는 구현하기 어려운 복잡한 모델을 만들 때는 nn.Module을 상속받아 구현할 수 있습니다.

import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super(MLP, self).__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(28*28, 128)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(128, 64)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 10)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        x = self.flatten(x)
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.softmax(self.fc3(x))
        return x

model = MLP()

구현 순서

  1. nn.Module을 상속한 클래스를 생성하고, __init__ 함수를 정의합니다.
    • 필요에 따라 하이퍼파라미터를 인자로 받을 수 있습니다.
  2. 모델에 필요한 레이어, 파라미터 등을 설정하는 코드를 __init__ 안에 구현합니다.
  3. forward 함수에서 입력 데이터에 적용할 연산(순전파 과정)을 구현합니다.
    • __init__에서 초기화한 레이어 등을 활용하여 순전파 과정을 구현합니다.
  4. 구현된 클래스로부터 모델 객체를 생성합니다.

4. 손실 함수와 모델 최적화

  • TensorFlow처럼 Adam, SGD를 비롯한 다양한 손실 함수와 최적화 함수를 모델 학습에 활용할 수 있습니다.
  • DataLoader와 손실 함수를 바탕으로 모델을 학습합니다.

손실 함수 (Loss Function)

torch.nn에서 MSELoss, CrossEntropyLoss 등 다양한 손실 함수를 필요에 따라 불러와서 사용할 수 있습니다.

대표적인 손실 함수는 다음과 같습니다.

  • nn.L1Loss
  • nn.MSELoss
  • nn.CrossEntropyLoss
  • nn.CTCLoss
  • nn.NLLLoss
import torch.nn as nn
import torch.optim as optim

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

참고: PyTorch 공식 문서 - Loss Functions

최적화 함수 (Optimizer)

손실 함수를 활용해 계산한 오차를 최소화하는 방향으로 모델의 가중치를 조정하는 알고리즘입니다.

torch.optim에서 SGD, Adam 등 다양한 최적화 함수를 불러와서 활용할 수 있습니다. 이때 PyTorch 모델의 파라미터를 optimizer에 할당하여 해당 파라미터가 최적화되도록 설정합니다. Sequential 모델과 nn.Module을 활용한 모델 모두 구분 없이 동일하게 사용할 수 있습니다.

참고: PyTorch 공식 문서 - Optimization Algorithms

PyTorch Optimizer 종류

알고리즘 torch.optim 특징
GD (경사하강법) (없음) 수학적 기울기(그라디언트)를 활용한 학습
SGD torch.optim.SGD Mini-batch를 활용한 효율적인 학습
Momentum torch.optim.SGD에서 momentum 인자에 0 초과 값 입력 SGD에 관성을 적용한 빠른 학습
AdaGrad torch.optim.Adagrad SGD에 가중치별 적응형 학습률 적용
RMSprop torch.optim.RMSprop AdaGrad에서 최근 정보에 더 집중
Adam torch.optim.Adam Momentum + RMSprop 결합, 일반적으로 가장 많이 사용됨

학습률(Learning Rate)

최적화 함수의 학습률은 별도의 인자(lr)를 입력하여 설정할 수 있습니다.

optimizer = optim.Adam(model.parameters(), lr=0.001)

5. 학습 Loop

모델을 학습 모드(model.train())로 설정한 후, PyTorch에서 모델을 학습시키는 과정은 다음과 같습니다.

  1. DataLoader에서 데이터와 라벨을 받아옵니다.
  2. 최적화 함수를 초기화하고, 모델에 데이터를 입력합니다.
  3. 모델의 예측값과 라벨값(참값)을 바탕으로 손실(Loss)을 계산하고, 역전파 연산을 수행합니다.
  4. 최적화 함수를 통해 모델의 파라미터(가중치)를 업데이트합니다.
  5. 이 과정을 모든 학습 데이터의 mini-batch에 대해 반복합니다.
epochs = 10
for epoch in range(epochs):
    model.train()
    for images, labels in train_loader:  # DataLoader
        optimizer.zero_grad()               # 최적화 함수 초기화
        outputs = model(images)             # 모델에 데이터를 입력하고 예측값 도출
        loss = criterion(outputs, labels)   # 모델의 예측값과 참값을 바탕으로 손실(Loss) 계산
        loss.backward()                     # 손실 함수의 역전파 연산
        optimizer.step()                    # 최적화 함수를 통한 모델 업데이트

마무리 정리

  • torch.nn의 Sequential 모델을 사용하면 간단한 구조의 모델을 빠르게 구현할 수 있습니다.
  • 복잡한 모델 구조가 필요할 때는 nn.Module을 상속받아 __init__과 forward 함수를 직접 정의합니다.
  • torch.nn의 손실 함수와 torch.optim의 최적화 함수를 조합하여 모델을 학습시킵니다.
  • 학습 Loop는 데이터 로드 → 초기화 → 순전파 → 손실 계산 → 역전파 → 파라미터 업데이트의 반복으로 이루어집니다.
