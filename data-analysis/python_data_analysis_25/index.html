[머신러닝 II] 분류(Classification)

2026년 7월 28일 화요일

들어가며

머신러닝의 핵심 분야인 ‘분류(Classification)‘는 정답이 있는 데이터를 학습해 새로운 입력이 어느 클래스에 속할지 예측하는 지도학습의 대표적 과제입니다.

이번 글에서는 이진 분류를 다루는 주요 알고리즘과 모델 평가 방법을 살펴봅니다.

1. 분류 개념과 로지스틱 회귀

머신러닝 분야

머신러닝은 크게 지도학습, 비지도학습, 강화학습으로 나뉩니다.

  • 지도학습: 회귀분석(Regression), 분류(Classification)
  • 비지도학습: 클러스터링(Clustering), 차원 축소(Dimensionality Reduction)
  • 강화학습

지도학습이란

컴퓨터에 정답이 있는 데이터를 학습시키는 방법으로, 주어진 입력으로부터 출력 값을 예측하고자 할 때 사용합니다.

  • 회귀분석(Regression): 연속적인 값을 예측
  • 분류(Classification): 주어진 입력 값이 어떤 클래스에 속할지에 대한 결과 값을 도출하는 알고리즘

문제 상황 가정해보기

해외 여행을 준비하면서 항공 지연을 피하고 싶다고 가정해봅니다.

이때 기상 정보(구름 양, 풍속 등)를 활용해 항공 지연 여부를 예측할 수 있다면 어떨까요?

  • 데이터: X = 과거 기상 정보(풍속), Y = 항공 지연 여부
  • 목표: 기상 정보에 따른 항공 지연 여부 예측
  • 해결 방안: 분류 알고리즘
풍속(m/s)지연 여부

분류 문제에 회귀 알고리즘을 그대로 적용할 수 없는 이유

일반적인 회귀 알고리즘(예: 선형 회귀)은 분류 문제에 그대로 사용할 수 없습니다.

선형 회귀는 -∞ ~ +∞ 사이의 값을 가질 수 있기 때문입니다.

우리의 목표는 지연 여부(0 또는 1)를 판별하는 것인데, 결과 값이 1000처럼 나온다면 해석이 어렵습니다.

$$ Y \approx \beta_0 + \beta_1 X $$

이를 해결하기 위해, 해당 클래스에 속할 확률인 0과 1 사이의 값만 출력하도록 회귀 알고리즘의 출력 범위를 수정한 모델이 바로 로지스틱 회귀(Logistic Regression) 입니다.

$$ 0 \leq Y \leq 1 $$

로지스틱 회귀

이진 분류(Binary Classification) 문제를 해결하기 위한 모델로, 결과 값을 최소값 0, 최대값 1로 수렴시키기 위해 시그모이드 함수(Sigmoid, logistic)를 사용합니다.

$$ \sigma = \frac{1}{1 + e^{-x}} $$

시그모이드 함수(로지스틱 함수)

$$ g(x) = \frac{1}{1 + e^{-x}} = \frac{e^x}{1 + e^x} $$

  • s자형 곡선을 갖는 함수
  • x값이 커질 경우, g(x)값은 점점 1에 수렴
  • x값이 작아질 경우, g(x)값은 점점 0에 수렴

확률 결과값 판별 방법, 결정 경계

데이터를 분류하는 기준 값을 결정 경계라고 하며, 일반적으로 출력 값(확률) 0.5를 기준으로 판별합니다.

로지스틱 회귀 특징

  • 주로 2개 값 분류(이진 분류)를 위해 사용
  • 선형 회귀를 응용한 알고리즘이기 때문에 회귀의 특징을 가짐

분류 모델 구현 - 데이터 분리

import pandas as pd
from sklearn.model_selection import train_test_split

# 데이터셋 불러오기
df = pd.read_csv('data.csv')

train, test = train_test_split(df, test_size=0.2, random_state=21)
  • train_test_split(): 데이터 세트를 분리해주는 함수
    • *arrays: 데이터세트
    • test_size: 테스트세트의 비율 (0~1)
    • random_state: 분할 과정에서의 무작위성 제어

로지스틱 회귀 구현

2. Support Vector Machine (SVM)

문제 정의와 해결 방안

  • 문제 정의: 양성(1)과 음성(0) 두 개의 결과값으로 분류되는 이진 분류 문제 (예: 지연 여부 판별, 이상 거래 판별)
  • 해결 방안: SVM(Support Vector Machine) 분류 알고리즘

SVM이란

데이터 포인트들 사이 최적의 결정 경계를 정의하는 모델로, 딥러닝 기술 등장 이전까지 가장 인기 있었던 분류 알고리즘입니다.

최적의 결정 경계

데이터 군으로부터 최대한 멀리 떨어진 경계를 의미합니다.

두 개의 후보 경계선이 있다면, 데이터로부터 더 멀리 떨어진 경계가 더 최적입니다.

서포트 벡터(Support Vector)

결정 경계와 가장 가까이 있는 데이터 포인트들을 서포트 벡터라고 합니다.

결정 경계 여유 (마진)

결정 경계와 서포트 벡터 사이의 거리를 마진(Margin) 이라고 하며, SVM은 이 마진을 최대화하는 결정 경계를 찾습니다.

Hard Margin vs. Soft Margin

이상치(Outlier) 허용 범위에 따라 두 가지로 구분됩니다.

  • Hard Margin: 엄격하게 두 개의 클래스를 분리하는 결정 경계를 구함
  • Soft Margin: 서포트 벡터가 위치한 경계선에 약간의 여유 변수를 둘 수 있음

SVM 특징

  • 선형 분류와 비선형 분류 모두 가능
  • 고차원 데이터에서도 높은 성능의 결과를 도출
  • 회귀에도 적용 가능

SVM 구현

from sklearn.svm import SVC

# 데이터 분리
train_X, test_X, train_y, test_y = train_test_split(X, y, test_size=0.2, random_state=0)

# 모델 생성
svm = SVC()
# 모델 학습
svm.fit(train_X, train_y)

# 테스트 데이터에 대한 예측
predicted = svm.predict(test_X)

SVM 중 분류 모델을 사용하고 싶을 땐 SVC를 import합니다.

3. 나이브 베이즈 분류

문제 정의와 해결 방안

10만 개의 메일 중 스팸 메일과 정상 메일을 분류하고 싶은 경우, 나이브 베이즈 분류 알고리즘을 활용할 수 있습니다.

나이브 베이즈 분류란

각 특징들이 독립적이며 서로 영향을 미치지 않을 것이라는 가정을 두고, 베이즈 정리를 활용한 확률 통계학적 분류 알고리즘입니다.

$$ P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{P(B|A)P(A)}{P(B)} $$

베이즈 정리 예시

맑은 날 비가 오지 않을 확률은 다음과 같이 계산할 수 있습니다.

$$ P(\text{비가 안옴} \mid \text{맑은 날}) = \frac{P(\text{맑은 날} \mid \text{비가 안옴}) \times P(\text{비가 안옴})}{P(\text{맑은 날})} $$

비가 옴비가 안옴
맑은 날2810
흐린 날5510
71320

문제 적용 (스팸 메일 분류)

  1. 스팸 메일과 정상 메일의 단어를 체크
  2. 새로운 메일의 단어들에 대한 확률로 스팸 메일을 구분
  3. P(스팸 | 단어1, 단어2, …) > P(정상 | 단어1, 단어2, …) 이면 스팸으로 판단

나이브 베이즈 분류 특징

  • 각 특징들이 독립이라면 다른 분류 방식에 비해 결과가 좋고, 학습 데이터도 적게 필요
  • 각 특징들이 독립이 아니라면(특징들이 서로 영향을 미치면) 분류 결과의 신뢰성 하락
  • 학습 데이터에 없는 범주의 데이터일 경우 정상적 예측 불가능

나이브 베이즈 구현

from sklearn.naive_bayes import GaussianNB

# 데이터 분리
train_X, test_X, train_y, test_y = train_test_split(X, y, test_size=0.2, random_state=0)

# 모델 생성
naive_model = GaussianNB()
# 모델 학습
naive_model.fit(train_X, train_y)

# 테스트 데이터에 대한 예측
predicted = naive_model.predict(test_X)

GaussianNB()는 각 특징이 정규분포(가우시안 분포)를 따른다고 가정하는 분류기입니다.

4. KNN (K-Nearest Neighbor)

문제 정의와 해결 방안

고객이 평가한 영화 평점 데이터를 기준으로 기존 보유 고객을 분류한 후, 새로 유입된 고객을 기준에 따라 분류하고자 하는 경우 KNN 알고리즘(K-Nearest Neighbor)을 활용할 수 있습니다.

KNN이란

기존 데이터 가운데 가장 가까운 k개의 이웃의 정보로 새로운 데이터를 예측하는 방법론입니다.

유사한 특성을 가진 데이터는 유사한 범주에 속하는 경향이 있다는 가정 하에 분류합니다.

  • K는 모델의 하이퍼파라미터로, 최적의 모델 성능을 찾기 위해 한 학습 사이클 종료 후 결과를 바탕으로 조정할 수 있습니다.
  • K값은 주로 홀수로 설정합니다. (동점 방지 목적)

예를 들어 새로운 고객 데이터가 들어왔을 때, k=1이면 가장 가까운 하나의 이웃 클래스로, k=3이면 가장 가까운 세 개의 이웃 중 다수인 클래스로 분류됩니다.

KNN 특징

  • 직관적이며 복잡하지 않은 알고리즘
  • 결과 해석이 쉬움
  • K값 결정에 따라 성능이 크게 좌우됨
    • 가능한 K 값을 모두 실험한다면 학습 시간이 길어질 수 있음

KNN 구현

from sklearn.neighbors import KNeighborsClassifier

# 데이터 분리
train_X, test_X, train_y, test_y = train_test_split(X, y, test_size=0.2, random_state=0)

# 모델 생성 (n_neighbors: k값 설정, 되도록 홀수로 설정, default=5)
knn_model = KNeighborsClassifier(n_neighbors=5)
# 모델 학습
knn_model.fit(train_X, train_y)

# 테스트 데이터에 대한 예측
predicted = knn_model.predict(test_X)

5. 분류 알고리즘 평가 지표

혼동 행렬(Confusion Matrix)

분류 모델의 성능을 평가하기 위해 사용되는 행렬입니다.

예측: Positive예측: Negative
실제: PositiveTrue PositiveFalse Negative (Type-2 error)
실제: NegativeFalse Positive (Type-1 error)True Negative
  • Positive(긍정 클래스, 양성): 모델이 관심 있는 클래스
  • Negative(부정 클래스, 음성): 모델이 관심 없는 클래스
  • 예시: 스팸 메일 분류기의 경우, 스팸 메일은 Positive, 비 스팸 메일은 Negative

정확도(Accuracy)

전체 데이터 중에서 제대로 분류된 데이터의 비율입니다.

$$ Accuracy = \frac{TP + TN}{TP + TN + FP + FN} $$

  • 모델이 얼마나 정확하게 분류하는지를 나타냄
  • 일반적으로 분류 모델의 주요 평가 방법으로 사용
  • 클래스 비율이 불균형할 경우, 평가 지표의 신뢰성을 잃음

불균형한 클래스에서의 정확도 문제

전체 100만 개 항공 데이터 중 90만 개가 정상 운행, 10만 개만 지연 운행인 데이터가 있다고 가정해봅시다.

$$ \text{정확도} = \frac{0\text{개} + 90\text{만개}}{100\text{만개}} = 90% $$

전체 결과가 모두 “지연되지 않았다"고 예측될 경우에도 정확도가 90%로 나오므로, 이 수치만으로 모델 성능을 단정하기에는 위험합니다. 다양한 평가지표를 함께 고려할 필요가 있습니다.

정밀도(Precision)

모델이 Positive라고 분류한 데이터 중 실제로 Positive인 데이터의 비율입니다.

$$ Precision = \frac{TP}{TP + FP} $$

  • 모델이 예측한 긍정 사례가 실제로 맞는 비율(=예측의 정확도)
  • 일반적으로 정밀도는 Type-1 Error를 줄이는 것이 중요한 상황에서 주로 사용
    • Type-1 Error: 실제로는 Negative인데 Positive로 예측한 사례

예: 스팸 메일 판정 문제에서 정상 메일(Negative)이 스팸(Positive)으로 잘못 분류(False Positive)될 경우, 중요한 메일을 전달받지 못하는 상황이 발생합니다.

재현율(Recall)

실제로 Positive인 데이터 중 모델이 Positive로 분류한 데이터의 비율입니다.

$$ Recall = \frac{TP}{TP + FN} $$

  • 모델이 실제 긍정 사례를 놓치지 않는 비율(=관심 사례 포착 정도)
  • 일반적으로 재현율은 Type-2 Error를 줄이는 것이 중요한 상황에서 주로 사용
    • Type-2 Error: 실제로는 Positive인데 Negative로 예측한 사례

예: 질병 진단에서 암 환자(Positive)를 놓치는 경우(False Negative)는 큰 위험을 초래하므로, Recall을 높여 실제 환자를 놓치지 않도록 해야 합니다.

F1 Score

정밀도와 재현율의 조화 평균입니다.

$$ F1 = \frac{2 \times Precision \times Recall}{Precision + Recall} $$

  • 모델의 정확성과 완전성을 동시에 고려하여 모델의 성능을 평가
  • 데이터 불균형이 심각할 때 사용

FPR (False Positive Rate)

실제로 Negative인 데이터 중 모델이 Positive로 분류한 데이터의 비율입니다.

$$ FPR = \frac{FP}{FP + TN} $$

예: 게임에서 비정상 사용자 검출 시 FPR이 높으면 정상 사용자를 비정상 사용자로 검출하는 경우가 많아지고, 이때 페널티를 부여하면 선의의 사용자가 피해를 입을 수 있습니다.

ROC Curve와 AUC

  • x축을 False Positive Rate, y축을 Recall(True Positive Rate) 값으로 시각화한 그래프
  • 커브가 왼쪽 위로 당겨질수록 Classifier의 성능이 향상됨을 의미
  • AUC(Area Under Curve) = ROC Curve 아래 면적 (AUC = 0.5인 경우 Classifier의 최하 성능)

평가 지표 구현 (혼동행렬 기반)

from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# 검증 데이터에 대한 예측
y_pred = model.predict(X_valid)

# 정확도 계산
accuracy = accuracy_score(y_valid, y_pred)

# 정밀도 계산
precision = precision_score(y_valid, y_pred)

# 재현율 계산
recall = recall_score(y_valid, y_pred)

# F1 Score 계산
f1 = f1_score(y_valid, y_pred)

print("Accuracy:", accuracy)
print("Precision:", precision)
print("Recall:", recall)
print("F1 Score:", f1)

마무리 정리

분류(Classification) 알고리즘의 핵심 원리와 평가 방법을 정리했습니다.

각 모델은 서로 다른 접근 방식으로 결정 경계를 찾으며, 상황에 맞는 알고리즘 선택이 중요합니다.

구분핵심 내용
로지스틱 회귀시그모이드 함수로 확률(0~1) 출력, 이진 분류에 사용
SVM마진 최대화하는 최적 결정 경계 탐색
KNN가까운 K개 이웃의 다수결로 분류
평가 지표Accuracy, Precision, Recall, F1 Score, ROC-AUC

정확도(Accuracy)만으로는 불균형 데이터를 평가하기 어렵습니다.

상황에 맞는 평가 지표를 선택하고 알고리즘을 비교해 보는 것이 분류 모델 실전의 핵심입니다.
