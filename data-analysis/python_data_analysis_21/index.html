[데이터 처리] 불균형한 데이터 처리

2026년 7월 24일 금요일

들어가며

머신러닝에서 클래스 간 데이터 수가 크게 차이 나는 데이터 불균형(Data Imbalance) 문제는 모델의 과적합을 유발할 수 있습니다.

본 글에서는 데이터 불균형의 개념과 이를 해소하기 위한 언더샘플링·오버샘플링 기법을 정리하였습니다.

불균형한 데이터 처리

사용 도구

구분 도구
데이터 Titanic 데이터셋 (PassengerId, Survived, Pclass 등)
데이터 조작 도구 Pandas
시각화 도구 Matplotlib, Seaborn

1. 데이터 불균형

데이터 불균형이란?

  • 추론하고자 하는 데이터의 분포가 다른(클래스 간 비율이 크게 차이 나는) 데이터
  • 모델의 과적합을 유발
  • 적절한 방식으로 처리해야 함

2. 데이터 불균형 처리

데이터 불균형 처리는 크게 언더샘플링(Undersampling) 과 오버샘플링(Oversampling) 으로 나뉩니다.

방법 설명 사용 조건
언더샘플링 다수 클래스 데이터를 더 많이 제거하여 분포를 일치 데이터가 충분한 경우 사용
오버샘플링 소수 클래스 데이터를 복제/생성하여 분포를 일치 데이터가 부족한 경우 사용

언더샘플링 방법

1. 랜덤 샘플링

  • 다수 클래스 데이터 중 랜덤하게 선택
  • 소수 클래스 데이터 수만큼 샘플링하여 데이터 수를 일치시킴

2. Tomek Links

  • 서로 다른 클래스 중 근접한(경계에 가까운) 다수 클래스 데이터를 삭제
  • 데이터의 경계를 더 명확히 함
  • 큰 데이터셋에서는 시간이 많이 소요됨

3. CNN Rule (Condensed Nearest Neighbor)

  • 소수 클래스와 근접한 다수 클래스 데이터를 샘플링
  • 경계 샘플들을 유지하여 데이터의 주요 구조와 패턴을 보존

오버샘플링 방법

1. Resampling

  • 소수 클래스 데이터를 랜덤하게 복제
  • 다수 클래스 데이터 수만큼 복제하여 수를 일치시킴

2. SMOTE (Synthetic Minority Over-sampling Technique)

  • K-NN 알고리즘으로 소수 클래스 데이터를 새롭게 생성
  • 과적합 문제 해결 가능
  • 생성된 데이터가 기존 분포와 다를 수 있다는 단점 존재

3. Borderline SMOTE

  • 클래스 경계에 속한 데이터에 SMOTE를 적용
  • 모델이 경계 영역에서 더 잘 작동하도록 함
  • 노이즈를 증폭시킬 위험이 있음

마무리 정리

구분 방법 핵심 아이디어
언더샘플링 랜덤 샘플링 다수 클래스에서 무작위 제거
언더샘플링 Tomek Links 경계 근접 데이터 제거
언더샘플링 CNN Rule 경계 구조를 보존하며 샘플링
오버샘플링 Resampling 소수 클래스 무작위 복제
오버샘플링 SMOTE K-NN 기반 합성 데이터 생성
오버샘플링 Borderline SMOTE 경계 영역 위주로 SMOTE 적용

데이터의 양과 특성, 그리고 모델이 처리해야 할 경계 영역의 중요도에 따라 적절한 샘플링 기법을 선택하는 것이 중요합니다.
