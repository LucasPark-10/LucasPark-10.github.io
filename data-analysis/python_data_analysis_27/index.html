[머신러닝 II] 의사결정나무(Decision Tree)

2026년 7월 30일 목요일

들어가며

의사결정나무는 직관적으로 이해하기 쉬운 시각적 분할 모델입니다.

여기서 한 단계 발전해 여러 나무를 합치는 앙상블 기법까지, 예측 성능을 높이는 주요 방법들을 정리했습니다.

1. 문제 제시

회귀 문제에는 단순/다중 선형 회귀, 다항 회귀 등이 있고, 분류 문제에는 로지스틱 회귀, 서포트 벡터 머신, 나이브 베이즈 분류기 등이 있습니다.

하지만 이러한 모델들은 원리가 복잡하고 이해하기 어렵다는 단점이 있습니다.

이를 해결하기 위한 방안이 바로 시각적으로 쉽게 이해할 수 있는 의사결정나무(Decision Tree) 모델입니다.

2. 의사결정나무란

의사결정나무는 반복적인 분할을 통해 데이터를 단계적으로 분류하는 모델입니다.

마치 스무고개와 같이 특정 질문들을 통해 정답을 찾아가는 방식이며, 최상단의 Root Node에서 마지막 Terminal Node까지 아래 방향으로 진행됩니다.

의사결정나무의 Node 구조

  • Root Node: 뿌리 노드, 최상단에 위치하며 전체 데이터를 포함합니다.
  • Terminal Node(Leaf Node): 최종 노드, 최하단에 위치하며 결과(예측값)가 저장되어 있습니다.
  • 서브 트리(Sub-tree): 전체 트리 중 일부 트리를 의미하며, 가지치기에 이용됩니다.

의사결정나무의 특징

  • 직관적이고 이해하기 쉽습니다.
  • 비선형 관계 모델링이 가능합니다.
  • 데이터 전처리에 덜 민감합니다.
  • 나무가 너무 깊어지면 과적합이 발생할 수 있습니다.

의사결정나무는 지도학습 알고리즘으로, 회귀와 분류 모두 적용 가능합니다.

3. 의사결정나무 - 회귀

회귀를 위한 의사결정나무 모델은 위에서 아래로 진행될수록 데이터의 구역을 나누는 방식으로 학습을 진행하고, 결과값을 예측합니다.

이때 겹치지 않는 구역으로 데이터를 나누게 되는데, 어떤 구역으로 어떻게 나눌지가 핵심 질문입니다.

RSS (Residual Sum of Squares)

어떤 구역으로 나눌지는 해당 구역에 있는 데이터들의 실제값(Y)과 예측값의 **오차 제곱합(RSS)**을 최소화하는 구역을 기준으로 정합니다.

$$RSS = \sum (y_i - \hat{y_i})^2$$

다만 RSS를 최소화하는 모든 구역을 한 번에 찾는 것은 계산적으로 불가능합니다.

그래서 위에서부터 순간순간마다 가장 최선의 선택을 하는 Top-down, Greedy Approach 방식을 사용합니다.

Greedy Approach

  • 가능한 모든 분할 기준을 시도해보고, 각 기준에 대해 분할 후의 결과를 평가합니다.
  • 분할 후 하위 노드의 데이터들이 더 작고 더 균일한 값들로 묶이도록 하는 분할 기준을 찾습니다.

회귀 의사결정나무 구현 (sklearn) 

from sklearn.tree import DecisionTreeRegressor

reg = DecisionTreeRegressor(max_depth = 5)  # 모델 생성
reg.fit(X, y)                                # 모델 학습
reg.predict(X_test)                          # 회귀 결과 반환
  • max_depth: 트리의 최대 깊이 (default = None)

4. 의사결정나무 - 분류

분류 문제에서는 구하고자 하는 것이 해당 구역의 평균값이 아니기 때문에 RSS를 그대로 사용할 수 없습니다.

대신 데이터의 **불순도(Impurity)**를 최소화하는 구역으로 나눕니다.

불순도(Impurity)

불순도는 다른 데이터가 섞여 있는 정도를 의미합니다.

불순도가 낮을수록 노드가 순수해지며, 대부분의 데이터가 동일한 클래스로 이루어졌다는 뜻입니다.

대표적으로 지니 지수, 엔트로피 등을 사용합니다.

지니 지수(Gini Index): 해당 구역 안에서 특정 클래스에 속하는 데이터의 비율을 모두 제외한 값으로, 다양성을 계산하는 방법입니다. 이진 분류일 때 다음과 같이 계산합니다.

$$Gini\ Index = 1 - (P(Yes))^2 - (P(No))^2$$

엔트로피(Entropy): 정보 이론에 기반한 척도로, 데이터가 얼마나 예측하기 어려운지를 나타내며 노드 내 클래스의 불확실성을 측정하는 방법입니다.

$$Entropy = -\sum_{i=1}^{C} p_i \log_2 p_i$$

분류 의사결정나무 구현 (sklearn) 

from sklearn.tree import DecisionTreeClassifier

clf = DecisionTreeClassifier(criterion='gini')  # 모델 생성
clf.fit(X, y)                                    # 모델 학습
clf.predict(X_test)                              # 분류 결과 반환
  • criterion: 분류하는 기준 (default = ‘gini’, {‘gini’, ’entropy’, ’log_loss’})

5. 앙상블 기법

앙상블 기법은 과적합 방지 및 더 높은 성능의 결과를 도출하도록 여러 모델을 활용하는 기법으로, 데이터가 복잡하거나 노이즈가 많은 경우 유용합니다.

대표적으로 Voting, Bagging(Bootstrap Aggregating), Boosting이 있습니다.

보팅(Voting)

여러 모델의 예측 결과값을 활용하여 투표를 통해 최종 예측값을 결정하는 방식입니다.

  • 회귀: 각 모델의 예측값 평균을 사용합니다.
  • 분류
    • 직접 투표(하드 보팅): 다수결 채택
    • 간접 투표(소프트 보팅): 확률의 평균

특징: 결과가 직관적이며 해석이 쉽고, 평균·다수결 채택 등의 간단한 연산을 사용합니다. 서로 다른 알고리즘을 사용한 여러 모델을 결합할 수 있습니다.

from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.ensemble import VotingClassifier

lr_clf = LogisticRegression()
knn_clf = KNeighborsClassifier()

vo_clf = VotingClassifier(estimators = [('LR', lr_clf), ('KNN', knn_clf)], voting='soft')  # 모델 생성
vo_clf.fit(train_X, train_y)   # 모델 학습
vo_clf.predict(test_X)         # 보팅 분류 결과 반환
  • estimators: 앙상블 학습을 진행할 분류 모델 설정. [('모델 이름1', 모델1), ('모델 이름2', 모델2), ...] 형식으로 전달
  • voting: 보팅 방식 설정 (default = ‘hard’, {‘hard’, ‘soft’})

배깅(Bagging)

복원 추출을 통해 랜덤 추출한 데이터를 생성하고, 각 데이터를 모델 학습하여 결합한 후, 학습된 모델의 예측 변수를 활용하여 최종 모델을 생성하는 방법입니다.

Bagging = Bootstrap + Aggregating

Bootstrap이란 데이터를 복원 추출하는 통계학적 방법으로, 데이터를 추출한 이후 다시 원 데이터로 복원한 후 다시 데이터셋을 추출하는 과정을 말합니다.

특징: Bootstrap 과정을 활용한 랜덤 샘플링으로 과적합을 방지할 수 있고, 복원 과정이 있어 불균형하거나 충분하지 않은 데이터에도 적용 가능합니다. 모델들이 서로 다른 데이터를 학습하여 각 모델에 다양성을 부여할 수 있습니다.

from sklearn.ensemble import BaggingClassifier
from sklearn.tree import DecisionTreeClassifier

ba_clf = BaggingClassifier(base_estimator = DecisionTreeClassifier(), n_estimators=100)  # 모델 생성
ba_clf.fit(train_X, train_y)   # 모델 학습
ba_clf.predict(test_X)         # 배깅 분류 결과 반환
  • base_estimator: 앙상블을 진행할 분류 모델 설정
  • n_estimators: 사용하고자 하는 분류 모델의 개수 (default = 10)

부스팅(Boosting)

여러 개의 약한 모델(Weak Learner)을 수정하여 강한 모델(Strong Learner)을 만드는 방법입니다.

독립적인 모델을 합산하여 산출하기보다는 기존의 모델을 개선시키는 방향의 앙상블 기법으로, 여러 개의 분류기가 순차적으로 학습을 수행하되 앞서 학습한 분류기가 잘못 예측한 데이터에 대해서는 다음 분류기에 가중치를 부여합니다.

의사결정트리에 앙상블 기법을 활용한 대표적인 모델로는 랜덤 포레스트, 부스팅 계열 모델(Ada Boost, Gradient Boosting, XGBoost, LGBM, CatBoost)이 있습니다.

6. 랜덤 포레스트와 Boosting 알고리즘

랜덤 포레스트

단일 모델 사용 시 과적합이 나타날 가능성이 높다면, 여러 개의 의사결정나무를 사용하는 랜덤 포레스트를 고려할 수 있습니다.

랜덤 포레스트는 의사결정트리와 Bagging 알고리즘을 결합한 것으로, 여러 개의 나무를 사용해 숲을 생성한다는 의미입니다.

동작 방식

  1. 데이터셋에서 Bootstrap을 통해 N개의 훈련 데이터셋을 생성합니다. (개별 데이터뿐 아니라 입력 변수에 대해서도 복원 추출을 함께 진행합니다.)
  2. 생성한 N개의 의사결정나무를 학습합니다.
  3. 학습된 나무들의 예측 결과값의 평균 또는 다수결 투표 방식을 이용하여 결합합니다.

특징: 의사결정나무와 동일하게 회귀와 분류 모두 적용 가능하며, 각 트리에서 사용된 특성의 중요도를 추정하여 변수 선택 및 해석에 유용합니다. 변수 일부를 사용하기 때문에 과적합을 방지할 수 있어, 안정적이고 강력한 모델로 일반적으로 높은 성능을 보입니다.

Ada Boost

Adaptive Boosting의 줄임말로, 이전 학습 과정에서 오분류한 데이터를 다음 학습 과정에서는 잘 분류할 수 있도록 반영해 나가는 알고리즘입니다.

이때 오차는 손실함수로 표현되며, 이 손실함수를 최적화하여 오차값을 최소화하는 모델의 인자를 찾습니다.

특징: 오분류 데이터에 대해 모델을 적합할 수 있지만, 계산 과정에 있어 병렬 수행이 불가능합니다. 다양한 약한 모델(Weak Learner)과 유연하게 결합하며 강한 모델을 생성하고, 가중치 업데이트 메커니즘을 통해 일반화 성능을 높여 잘 과적합하지 않습니다.

Gradient Boosting

Gradient Descent(경사 하강법)와 Boosting을 결합한 방식으로, Ada Boost와 동일한 원리이지만 가중치 업데이트 과정에서 Gradient Descent를 사용합니다.

Gradient Descent는 함수의 기울기(Gradient)를 이용하여 최소값을 찾는 최적화 알고리즘입니다.

특징: 계산량이 많이 필요하지만 높은 성능을 도출합니다. 효율적 연산이 가능하도록 파이썬 라이브러리 내에 정의되어 있으며, 이를 응용한 다양한 모델(XGBoost, LGBM, CatBoost)이 개발되었습니다.

7. Gradient Boosting 기반 모델 소개

Gradient Boosting 기반의 성능이 향상된 다양한 모델이 개발되어, 간단한 모듈 불러오기만으로 사용이 가능합니다.

import xgboost as xgb      # XGBoost
import lightgbm as lgb     # LightGBM
from catboost import CatBoostClassifier, CatBoostRegressor  # CatBoost

eXtreme Gradient Boosting (XGBoost)

일반 Gradient Boosting 모델과 작동 원리는 동일하지만, 불순도(Impurity)를 감소하는 방향만 강조되는 트리에서 정규화를 추가하여 모델의 복잡성을 고려한 정규화된 모델을 사용해 과적합을 방지합니다.

특징: 분산/병렬 처리를 통해 실행 속도를 보완했으며, 대부분의 문제에서 양호한 예측 성능을 보입니다. 다양한 하이퍼파라미터 지원 및 조절을 통해 과적합 방지에 효율적입니다.

Light Gradient Boosting Model (LGBM)

XGBoost에 비해 더 가볍고 빠른 실행 속도를 가진 모델이며, 범주형 변수 처리 지원 기능이 추가되었습니다.

특징: 대용량 데이터에서의 실행 속도가 개선되었고, 기존 XGBoost 대비 적은 메모리를 사용합니다. 다만 적은 수의 데이터에 적용 시 과적합 문제가 발생할 가능성이 있습니다.

Categorical Boosting (CatBoost)

Categorical과 Boosting Model을 결합한 이름으로, 범주형 변수를 위한 다양한 기능을 지원하는 부스팅 모델입니다.

특징: 범주형 변수에 대한 전처리 문제를 해결하며, 범주형 변수를 자동으로 처리해 타입 변환 오류를 피할 수 있습니다. 범주형 변수와 수치형 변수들의 조합(Combination)을 처리하고, 변수 간의 상관관계를 계산함과 동시에 속도를 개선했습니다. Multiple-category 데이터를 다룰 때 유용합니다.

마무리 정리

추가 핵심 포인트

  • RSS: 실제값과 예측값 오차 제곱합, 회귀의 분할 기준
  • 지니 지수: 1 − P(Yes)² − P(No)², 이진 분류 불순도 측정
  • 엔트로피: 정보 이론 기반, 클래스 불확실성 측정
  • 앙상블 핵심: Voting(투표), Bagging(복원 추출+병렬), Boosting(순차 가중치 수정)

단일 의사결정나무는 해석이 쉬운 대신 과적합 위험이 있습니다.

이를 보완하기 위해 랜덤 포레스트로 분산을 줄이고, Gradient Boosting 계열(XGBoost/LGBM/CatBoost)로 성능을 높일 수 있으며, 데이터 특성과 규모에 맞춰 적절한 모델을 선택하면 됩니다.
