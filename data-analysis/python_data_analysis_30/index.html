[딥러닝 기초] 딥러닝 학습의 문제점

2026년 8월 2일 일요일

들어가며

이 글에서는 딥러닝 학습의 문제점을 정리한 내용입니다.

딥러닝 모델을 학습시키는 과정에서 발생하는 대표적인 문제점들과 그 해결 기법들을 살펴보겠습니다.

1. 딥러닝 모델 학습의 문제점

데이터의 증가와 딥러닝 모델의 한계점

실생활 문제에서 다루는 데이터의 차원이 증가하고 구조가 복잡해지면서, 다양한 문제가 발생하게 되었습니다.

이로 인해 기술력의 부족으로 딥러닝 기술이 실질적인 한계를 마주하게 되었습니다.

딥러닝 학습에서 발생하는 대표적인 문제점 4가지

  1. 학습 속도 문제
  2. 기울기 소실 문제
  3. 초기값 설정 문제
  4. 과적합 문제

1. 학습 속도 문제

데이터의 개수가 폭발적으로 증가함에 따라, 딥러닝 모델 학습에 소요되는 시간도 함께 증가하게 되었습니다.

2. 기울기 소실 문제

더 깊고 더 넓은 신경망을 학습시키는 과정에서, 출력값에서 멀어질수록(즉 입력층에 가까워질수록) 학습이 잘 이루어지지 않는 현상이 발생합니다.

3. 초기값 설정 문제

가중치의 초기값을 어떻게 설정하느냐에 따라 모델의 성능 차이가 매우 크게 발생합니다.

4. 과적합 문제

학습 데이터(training data)에 모델이 지나치게 최적화되어, 테스트 데이터(test data)에 대한 모델의 성능이 오히려 저하되는 현상입니다.

참고: 1990년대 두 번째 AI 겨울

  • 1958년: 퍼셉트론(Perceptron) 등장
  • 1969년: 첫 번째 AI 겨울(First AI winter) 시작
  • 1986년 ~ 1990년: 두 번째 AI 겨울(Second AI winter)
  • 2012년: 딥러닝 혁명(Deep learning revolution)
  • 2020년: 현재에 이르는 발전

위에서 언급한 학습 속도, 기울기 소실, 초기값 설정, 과적합 문제들은 딥러닝이 두 번째 겨울을 겪게 된 주요 원인이기도 합니다.

2. 학습 속도 문제와 최적화 알고리즘

학습 속도 문제의 발생 원인

기존의 경사하강법(Gradient Descent, GD)은 **전체 학습 데이터 셋(Full-batch)**을 사용하여 손실 함수를 계산하기 때문에 계산량이 너무 많아지는 문제가 있습니다.

해결 방법: SGD(Stochastic Gradient Descent)

전체 데이터가 아닌 **부분 데이터(mini-batch)**만 활용하여 손실 함수를 계산하는 방식입니다.

GD vs SGD

구분 방식
Gradient Descent 전체 Training Data(Full-batch)를 한 번에 사용
Stochastic Gradient Descent Training Data를 여러 개의 Mini-batch로 나누어 사용

SGD는 다소 부정확할 수 있지만, 계산 속도가 훨씬 빠르기 때문에 같은 시간에 더 많은 step을 진행할 수 있다는 장점이 있습니다.

SGD의 한계

1. Gradient 방향성 문제

SGD는 gradient 값을 계산할 때 mini-batch에 따라 gradient의 방향 변화가 크다는 한계가 있습니다.

2. Learning Rate 설정 문제

  • Learning rate가 너무 높으면(Too high): 손실 함수의 최솟값 주변을 크게 벗어나며 진동하게 됩니다.
  • Learning rate가 너무 낮으면(Too low): 지역 최솟값(local minima)에 갇히거나 수렴 속도가 매우 느려집니다.

다양한 최적화 알고리즘의 등장

SGD의 한계를 극복하기 위해 다음과 같은 최적화 알고리즘들이 발전해왔습니다.

GD → SGD → (Gradient 방향) → Momentum ─┐
              ↓                        ├─→ Adam
         (Learning rate) → Adagrad → RMSProp
알고리즘 핵심 아이디어
GD 모든 데이터를 검토한 뒤 방향을 찾음
SGD Mini-batch를 사용하여 검토한 뒤 자주 방향을 찾음
Momentum 관성의 개념을 도입하여, 과거에 이동했던 방향을 기억하면서 그 방향으로 일정 정도 추가 이동
Adagrad 가중치의 변화량에 따라 learning rate를 조절 (많이 변화한 변수는 learning rate를 작게, 적게 변화한 변수는 크게)
RMSProp Adagrad가 학습을 진행할수록 learning rate가 지나치게 줄어드는 문제를 해결. 과거의 기울기는 잊고 새로운 기울기 정보를 더 크게 반영
Adam Momentum과 RMSProp의 장점을 결합한, 가장 발전된 최적화 알고리즘

Momentum 예시: without momentum(관성 없이 지그재그로 이동)에 비해 with momentum(관성을 반영하여 더 부드럽고 빠르게 수렴)이 더 효율적으로 최솟값에 도달합니다.

Adagrad의 한계: 과거의 기울기를 제곱하여 계속 누적하기 때문에, 학습이 진행될수록 갱신 강도가 약해져 결국 학습이 거의 이루어지지 않는 단점이 있습니다.

3. 기울기 소실 문제와 방지 기법

딥러닝 모델 학습 방법 되짚어보기

딥러닝은 목표(target) 값과 실제 모델이 예측한 출력(output) 값이 얼마나 차이나는지를 구한 후, 그 오차값을 다시 뒤로 전파해가며(backpropagation) 가중치와 같은 변수들을 갱신하는 알고리즘입니다.

이때 특정 가중치의 gradient를 구하기 위해서는 그 전단(다음 층)의 계산 값이 필요합니다.

기울기 소실 문제(Vanishing Gradient)의 발생 원인

Sigmoid 함수와 같이 양 끝단의 기울기가 0에 가까운 활성화 함수를 사용하면, 역전파 과정에서 기울기가 0에 가까운 값으로 계속 전달되면서 중간 전달값이 점점 사라지는 문제가 발생합니다.

신경망이 깊어질수록(층이 많아질수록) 이러한 기울기 소실이 반복적으로 누적되며, 입력층에 가까운 층일수록 학습이 잘 이루어지지 않게 됩니다.

해결 방법 1: ReLU 함수

$$ReLU(x) = \max(0, x)$$

기존에 사용하던 sigmoid 함수 대신 ReLU 함수를 활성화 함수로 사용하여 기울기 소실 문제를 해결할 수 있습니다.

ReLU는 입력값이 양수인 구간에서는 기울기가 항상 1이기 때문에, 깊은 신경망에서도 기울기가 소실되지 않고 잘 전달됩니다.

해결 방법 2: Tanh 함수

$$Tanh(x) = \frac{e^{2x}+1}{e^{2x}-1}$$

일반적으로는 내부 Hidden Layer에는 ReLU를 적용하고, Output Layer에서만 Tanh를 적용하는 방식이 활용됩니다.

4. 초기값 설정 문제와 방지 기법

잘못된 초기값 설정 - 초기화의 중요성

가중치의 초기값을 잘못 설정하면 학습 초기부터 문제가 발생할 수 있습니다.

예를 들어 가중치를 100으로, 편향(bias)을 50으로 초기화한 경우 활성화 함수(sigmoid)에 입력되는 값이 지나치게 커져(예: 51), sigmoid 함수의 기울기가 0에 매우 가까워지는 구간에 위치하게 됩니다.

이 경우 gradient 값이 0.00…01 수준으로 매우 작아져 학습이 제대로 이루어지지 않습니다.

가중치 초기화(Weight Initialization)의 핵심

가중치 초기화의 핵심은 활성화 함수의 입력 값이 너무 커지거나 작아지지 않도록 만들어주는 것입니다.

초기화 설정 문제 해결을 위한 Naïve한 방법

  • 표준 정규분포를 이용한 초기화: 레이어를 거칠수록 출력값이 0과 1 양 극단으로 쏠리는 경향이 나타납니다.
  • 표준편차 0.01의 정규분포를 이용한 초기화: 레이어를 거칠수록 출력값이 특정 값(예: 0.5) 부근으로 지나치게 쏠리는 경향이 나타납니다.

두 방법 모두 층이 깊어질수록 값의 분포가 한쪽으로 치우치는 문제가 있어, 효과적인 초기화 방법이라 보기 어렵습니다.

Xavier 초기화 방법

표준 정규 분포를 입력 개수의 제곱근으로 나누어주는 방식입니다.

Sigmoid와 같은 S자 형태의 활성화 함수를 사용할 경우, 각 층의 출력 값들이 정규 분포 형태를 유지해야 안정적인 학습이 가능합니다.

주의할 점: Xavier 초기화는 ReLU 함수에는 적합하지 않습니다. ReLU와 함께 사용할 경우 레이어를 거쳐갈수록 값이 0으로 수렴해버리는 문제가 발생합니다.

He 초기화 방법

표준 정규 분포를 입력 개수 절반의 제곱근으로 나누어주는 방식입니다.

ReLU 함수와 He 초기화를 함께 사용하면, 10개 층을 거치더라도 평균과 표준편차가 0으로 수렴하지 않고 안정적으로 유지됩니다.

적절한 가중치 초기화 방법 정리

활성화 함수 권장 초기화 방법
Sigmoid, Tanh Xavier 초기화
ReLU 계열 He 초기화

최근 대부분의 딥러닝 모델에서는 He 초기화를 주로 선택하고 있습니다.

5. 과적합 문제와 방지 기법

과적합(Overfitting)이란, 학습 데이터에 모델이 지나치게 최적화되어 오히려 테스트 데이터에 대한 성능이 저하되는 현상을 말합니다.

학습이 진행됨에 따라 Training error는 계속 감소하지만, 일정 시점 이후로 Testing error는 다시 증가하는 형태로 나타납니다.

이를 방지하기 위해 다음과 같은 기법들이 사용됩니다.

  • 정규화(Regularization)
  • 드롭아웃(Dropout)
  • 배치 정규화(Batch Normalization)

정규화(Regularization)

모델이 복잡해질수록 파라미터(parameter)의 수가 많아지고, 그 절댓값도 커지는 경향이 발생합니다.

이때 기존 손실함수에 규제항을 더해줌으로써 과적합을 억제하고 더 일반화된 최적값을 찾을 수 있습니다.

L1 정규화 (Lasso Regularization)

  • 가중치의 절댓값의 합을 규제 항으로 정의합니다.
  • 작은 가중치들이 거의 0으로 수렴하여, 몇 개의 중요한 가중치들만 남게 됩니다.

L2 정규화 (Ridge Regularization)

  • 가중치의 제곱의 합을 규제 항으로 정의합니다.
  • L1 정규화에 비해 0으로 수렴하는 가중치가 적으며, 큰 값을 가진 가중치를 더욱 강하게 제약하는 효과가 있습니다.

드롭아웃(Dropout)

각 layer마다 일정 비율의 뉴런을 임의로 drop(비활성화)시켜, 나머지 뉴런들만으로 학습을 진행하는 방법입니다.

드롭아웃을 적용하면 학습될 때마다 활성화되는 노드와 가중치들이 매번 달라지게 됩니다.

적용 방법

  • 다른 정규화 기법들과 상호 보완적으로 함께 사용할 수 있습니다.
  • Drop된 뉴런은 backpropagation 시 신호를 전달하지 않습니다(신호 차단).
  • 다만 Test(추론) 단계에서는 모든 뉴런에 신호를 전달합니다.

배치 정규화(Batch Normalization)

정규화(Normalization)를 처음 입력 데이터(Input data)에만 적용하는 것이 아니라, 신경망 내부 Hidden Layer의 입력값에도 적용하는 기법입니다.

일반적으로 Fully connected 층과 활성화 함수(Activation function) 사이에 위치합니다.

배치 정규화의 장점

  • 매 층(Layer)마다 정규화를 진행하므로, 가중치 초기값에 크게 의존하지 않아도 됩니다. (초기화의 중요도 감소)
  • 과적합을 억제하는 효과가 있어 Dropout, L1/L2 정규화의 필요성이 감소합니다.
  • 핵심적인 효과는 학습 속도의 향상입니다.

마무리 정리

딥러닝 모델 학습 과정에서 발생하는 네 가지 대표적인 문제(학습 속도, 기울기 소실, 초기값 설정, 과적합)와 이를 해결하기 위한 다양한 기법들을 살펴보았습니다.

  • 학습 속도 문제 → SGD 및 Momentum, Adagrad, RMSProp, Adam 등의 최적화 알고리즘
  • 기울기 소실 문제 → ReLU, Tanh 등 활성화 함수 개선
  • 초기값 설정 문제 → Xavier 초기화, He 초기화
  • 과적합 문제 → L1/L2 정규화, 드롭아웃, 배치 정규화

이러한 기법들은 서로 독립적이지 않고 상호 보완적으로 함께 사용되는 경우가 많으며, 실제 모델 설계 시 활성화 함수, 초기화 방법, 정규화 기법을 종합적으로 고려하는 것이 중요합니다.
