[머신러닝 분류 모델] Ensemble Learning

2026년 8월 17일 월요일

Voting → Bagging → Random Forest → Boosting → AdaBoost → Gradient Boosting

1. Ensemble Learning이란?

하나의 모델만 사용하는 대신

여러 모델의 예측을 결합하여 더 안정적이거나 강력한 모델을 만드는 방법

입니다.

예:

Logistic → 고양이
SVM      → 고양이
Tree     → 강아지
RF       → 고양이

다수결을 사용하면 최종 결과는 고양이가 됩니다.

2. Ensemble의 큰 두 종류

앙상블을 크게 보면 두 방향으로 나눌 수 있습니다.

Aggregation

여러 모델의 결과를 합친다.

대표:

  • Voting
  • Bagging
  • Random Forest

Boosting

모델을 순차적으로 학습하면서 이전 모델의 약점을 보완합니다.

대표:

  • AdaBoost
  • Gradient Boosting

3. Voting

Hard Voting

각 모델의 최종 클래스를 투표합니다.

모델 1 → A
모델 2 → A
모델 3 → B

→ A

Soft Voting

각 모델이 출력한 확률을 이용합니다.

Model 1
A = 0.8

Model 2
A = 0.7

Model 3
A = 0.6

각 모델의 확률을 평균 또는 가중 평균하여 최종 클래스를 결정합니다.

Soft Voting은 모델의 확률 정보를 활용한다는 점이 핵심입니다.

4. Bagging

Bagging은 Bootstrap Aggregating의 줄임말입니다.

핵심은

같은 종류의 모델을 여러 개 만들되 서로 다른 Bootstrap 데이터로 학습시키고 결과를 결합하는 것

입니다.

원본 데이터
     ↓
Bootstrap Sampling
     ↓
 ┌──────┬──────┬──────┐
 ↓      ↓      ↓
Tree1  Tree2  Tree3 ...
 └──────┴──────┴──────┘
          ↓
       결과 취합

5. Bootstrap

Bootstrap은 복원 추출입니다.

원본 데이터가

A B C D E

라면 Bootstrap Sample은

A C C E B

처럼 같은 데이터가 여러 번 선택될 수 있습니다.

반대로 선택되지 않은 데이터도 생긴다.

이 데이터가 OOB(Out-of-Bag) 데이터다.

데이터 수가 충분히 크면 약 **36.8%**의 데이터가 하나의 Bootstrap 표본에 선택되지 않는 성질이 있습니다.

6. Random Forest

Random Forest는 쉽게 말해

Decision Tree 여러 개를 결합한 모델

입니다.

좀 더 정확하게는

Decision Tree + Bootstrap Sampling + Random Feature Selection + Aggregation

으로 이해하면 좋습니다.

Bootstrap 데이터
      ↓
Tree 1 ← 일부 Feature
Tree 2 ← 일부 Feature
Tree 3 ← 일부 Feature
Tree 4 ← 일부 Feature
...
      ↓
Voting
      ↓
최종 예측

각 Tree가 서로 다른 데이터와 Feature를 사용하게 하여 모델의 다양성을 높인다.

7. Random Forest의 장점

  • 단일 Decision Tree보다 안정적인 경우가 많다.
  • 과적합을 줄이는 데 도움이 됩니다.
  • 비선형 관계를 처리할 수 있습니다.
  • Feature Importance를 확인할 수 있습니다.
  • 별도의 복잡한 Feature Scaling이 필수적이지 않다.

8. Feature Importance

Random Forest에서는 각 Feature의 상대적인 중요도를 확인할 수 있습니다.

예:

age             0.32
income          0.25
education       0.18
...

이를 통해 모델이 어떤 변수를 중요하게 사용했는지 살펴볼 수 있습니다.

다만 주의해야 합니다.

Feature Importance가 높다고 해서 그 변수가 결과의 원인이라는 뜻은 아니다.

즉, 중요도와 인과관계는 다르다.

9. Boosting

Bagging과 Boosting의 차이가 중요합니다.

Bagging

Tree 1
Tree 2
Tree 3
Tree 4
 ↓
상대적으로 독립적으로 학습
 ↓
결과 취합

Boosting

Model 1
 ↓
오류 확인
 ↓
Model 2
 ↓
오류 보완
 ↓
Model 3
 ↓
계속 보완

즉,

Boosting = 이전 모델의 약점을 다음 모델이 보완

10. AdaBoost

AdaBoost에서는 데이터마다 가중치가 있습니다.

처음에는 모든 데이터가 동일한 가중치를 가진다.

모든 데이터
↓
동일한 가중치

첫 번째 모델을 학습한 뒤 틀린 데이터의 가중치를 높인다.

모델 1

A 맞음
B 맞음
C 틀림
D 맞음
E 틀림

↓

C와 E의 가중치 ↑

↓

모델 2가 C와 E를 더 중요하게 학습

AdaBoost의 핵심

잘못 분류된 데이터에 더 집중하면서 다음 모델을 학습합니다.

11. AdaBoost 수식

가중치가 적용된 오류율:

$$ \epsilon_m = \frac{\sum_i w_{m,i} , I(k_m(x_i) \neq y_i)}{\sum_i w_{m,i}} $$

모델 가중치:

$$ \alpha_m = \frac{1}{2} \log \frac{1-\epsilon_m}{\epsilon_m} $$

잘 맞추는 모델일수록 더 큰 영향력을 갖는다.

12. Gradient Boosting

Gradient Boosting도 이전 모델이 부족한 부분을 다음 모델이 보완하는 방식입니다.

핵심적으로 Residual(잔차)을 생각하면 이해하기 쉽습니다.

예:

실제값 = 100
현재 예측 = 70

Residual = 30

다음 모델은 이 부족한 부분을 설명하도록 학습합니다.

그래서 최종적으로

$$ \text{최종 모델} = \text{기존 모델} + \text{새로운 모델} $$

형태로 모델을 점점 개선합니다.

18. 마지막 10문장

  1. 로지스틱 회귀는 선형식을 Sigmoid에 넣어 확률을 만듭니다.
  2. SVM은 클래스 사이의 Margin을 최대화합니다.
  3. Support Vector는 결정경계를 결정하는 핵심 데이터다.
  4. Kernel SVM은 Kernel Trick을 이용해 비선형 문제를 해결합니다.
  5. Naive Bayes는 Bayes 정리와 조건부 독립 가정을 이용합니다.
  6. Laplace Smoothing은 확률이 0이 되는 문제를 막는다.
  7. Decision Tree는 Entropy를 줄이고 Information Gain을 크게 만드는 방향으로 분기합니다.
  8. Accuracy만으로 모델을 평가하면 불균형 데이터에서 잘못된 판단을 할 수 있습니다.
  9. Random Forest는 여러 Decision Tree를 결합하는 Bagging 계열 모델입니다.
  10. Boosting은 이전 모델이 틀린 부분을 다음 모델이 보완하도록 만듭니다.

한 문장으로 전체 수업 정리

머신러닝 분류에서는 여러 방법(Logistic, SVM, Naive Bayes, Tree)으로 데이터를 분류하고, Confusion Matrix 기반의 다양한 평가 지표로 모델을 비교한 뒤, Bagging이나 Boosting 같은 Ensemble 방법으로 성능과 안정성을 높인다.
