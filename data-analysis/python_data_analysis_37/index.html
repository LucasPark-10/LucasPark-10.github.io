[머신러닝 분류 모델] 확률로 분류하기 - Naive Bayes

2026년 8월 11일 화요일

이번 글에서는 Bayes 정리 → 조건부 독립 → Naive Bayes → Laplace Smoothing → 텍스트 분류를 정리합니다.

1. Bayes 정리

Naive Bayes의 출발점은 Bayes 정리다.

$$ P(Y|X) = \frac{P(X|Y)P(Y)}{P(X)} $$

각 항의 의미는 다음과 같습니다.

기호의미
$P(Y|X)$사후확률
$P(X|Y)$가능도
$P(Y)$사전확률
$P(X)$증거

분류에서는 각 클래스의 사후확률을 비교하여 가장 높은 클래스를 선택합니다.

2. Naive Bayes란?

Naive Bayes는 Bayes 정리를 이용하는 확률 기반 분류 모델입니다.

핵심은 특징들이 조건부 독립이라고 가정한다는 것입니다.

예를 들어 이메일에

무료
당첨
쿠폰

이라는 단어가 있다면

$$ P(X|Y) = P(x_1|Y)P(x_2|Y)P(x_3|Y) $$

처럼 계산할 수 있습니다.

현실에서 단어들이 완전히 독립인 것은 아니지만, 이 가정 덕분에 계산이 매우 단순해진다.

3. Naive Bayes의 종류

모델주로 사용하는 데이터
GaussianNB연속형 데이터
BernoulliNB0/1 데이터
MultinomialNB빈도/count 데이터, 텍스트

특히 문서나 스팸 메일 같은 텍스트 분류에서는 Multinomial Naive Bayes가 자주 사용됩니다.

4. Laplace Smoothing

Naive Bayes에서 중요한 문제가 있습니다.

훈련 데이터에 한 번도 등장하지 않은 단어가 있다면

$$ P(word|class)=0 $$

이 됩니다.

확률을 여러 개 곱하기 때문에 하나라도 0이면 전체 확률도 0이 됩니다.

이를 해결하기 위한 방법이 Laplace Smoothing입니다.

대표적인 형태는

$$ P = \frac{N+\alpha}{N_{total}+\alpha V} $$

입니다.

핵심

Laplace Smoothing = 0 확률 방지

5. 텍스트 분류와 로그 확률

텍스트에서는 수많은 단어의 확률을 곱해야 합니다.

예를 들어

$$ 0.001\times0.002\times0.0001\times… $$

처럼 값이 매우 작아질 수 있습니다.

이런 문제를 Underflow라고 합니다.

그래서 로그를 사용합니다.

$$ \log(ab)=\log a+\log b $$

즉,

확률 곱셈
 ↓
로그 변환
 ↓
로그 확률 덧셈

으로 바꿀 수 있습니다.

6. Naive Bayes의 장점

  • 학습과 예측이 빠르다.
  • 비교적 적은 데이터에서도 잘 작동할 수 있습니다.
  • 텍스트 분류에 강하다.
  • 구현이 간단하다.
  • 확률 기반 모델이라 결과를 확률적으로 해석할 수 있습니다.

단점

  • 조건부 독립 가정이 현실과 다를 수 있습니다.
  • 변수 간 상호작용을 충분히 반영하지 못할 수 있습니다.
  • 확률이 0이 되는 문제를 별도로 처리해야 합니다.

7. 전체 흐름

입력 데이터
 ↓
Bayes 정리
 ↓
각 클래스의 사후확률 계산
 ↓
조건부 독립 가정으로 계산 단순화
 ↓
가장 높은 확률의 클래스 선택

텍스트라면 추가로

단어 빈도
 ↓
Naive Bayes
 ↓
Laplace Smoothing
 ↓
로그 확률 계산
 ↓
스팸 / 정상 등 분류

핵심 암기

Naive Bayes = Bayes 정리 + 조건부 독립 가정

Laplace Smoothing = 0 확률 방지

로그 확률 = Underflow 방지

한 문장 정리

Naive Bayes는 Bayes 정리와 조건부 독립 가정을 이용하여 각 클래스의 확률을 계산하는 빠르고 간단한 분류 모델이며, 특히 텍스트 분류에서 유용하다.
