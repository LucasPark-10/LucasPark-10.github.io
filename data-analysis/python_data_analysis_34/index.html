[머신러닝 분류 모델] 지도학습부터 앙상블까지

2026년 8월 8일 토요일

머신러닝 분류 모델 완벽 정리

지도학습부터 분류 알고리즘, 모델 평가와 앙상블까지

머신러닝을 공부하면서 가장 어려웠던 점은 개별 개념을 이해하는 것보다 서로 다른 개념들이 어떻게 연결되는지를 파악하는 것이었습니다.

로지스틱 회귀, SVM, Naive Bayes, Decision Tree, Random Forest, AdaBoost, Gradient Boosting처럼 모델의 종류도 많고,

Entropy, Information Gain, Maximum Likelihood, Margin, Kernel, Precision, Recall, AUC 등 처음 보면 서로 전혀 관계가 없어 보이는 개념도 계속 등장했습니다.

하지만 전체 구조를 한 번에 보면 생각보다 단순합니다.

데이터를 보고 → 분류 모델을 학습하고 → 예측하고 → 성능을 평가하고 → 필요하면 여러 모델을 결합한다.

이제 나오는 글들은 이전 배운 내용 포함해서 머신러닝 내용을 흐름에 맞춰 다시 정리해보겠습니다.

1. 먼저 머신러닝이란?

머신러닝(Machine Learning)은 데이터를 이용하여 컴퓨터가 데이터 속의 패턴이나 관계를 학습하고 새로운 데이터에 대한 예측을 수행하도록 만드는 방법입니다.

전통적인 프로그래밍에서는 사람이 규칙을 직접 작성합니다.

입력 + 사람이 만든 규칙
        ↓
      결과

머신러닝에서는 데이터와 정답을 이용해 컴퓨터가 규칙을 학습합니다.

데이터 + 정답
     ↓
   학습
     ↓
   모델
     ↓
새로운 데이터
     ↓
   예측

따라서 머신러닝에서 중요한 것은 단순히 “모델을 실행하는 것"이 아니라,

  1. 어떤 데이터를 사용하는가?
  2. 무엇을 예측하는가?
  3. 어떤 모델을 사용하는가?
  4. 모델이 얼마나 잘 예측하는가?

를 함께 이해하는 것이다.

2. 지도학습과 비지도학습

머신러닝은 여러 방식으로 나눌 수 있지만, 가장 먼저 이해해야 할 구분은 지도학습과 비지도학습이다.

지도학습(Supervised Learning)

정답(Label)이 있는 데이터를 사용하여 학습합니다.

입력 데이터 X + 정답 y
          ↓
        학습
          ↓
        모델
          ↓
새로운 X → y 예측

예를 들어,

공부 시간 → 시험 점수

처럼 정답이 있는 데이터를 학습할 수 있다.

지도학습은 대표적으로 회귀(Regression)와 분류(Classification)로 나뉩니다.

비지도학습(Unsupervised Learning)

정답 Label이 없는 데이터를 이용해 데이터의 구조나 패턴을 찾습니다.

예:

고객 데이터
 ↓
비슷한 고객끼리 그룹화
 ↓
고객군 발견

대표적인 방법으로 군집화(Clustering) 등이 있습니다.

이번 시리즈에서 집중하는 부분은 지도학습 중 분류 문제입니다.

3. 분류(Classification)란?

분류는 입력 데이터를 보고 미리 정해진 범주(Class) 중 하나를 예측하는 문제입니다.

예를 들어 이메일을 생각해보자.

입력 데이터
   ↓
"무료 쿠폰 당첨!"
   ↓
분류 모델
   ↓
스팸

정답이

Spam
Normal

처럼 범주형 값으로 존재한다면 이것은 분류 문제다.

4. 회귀와 분류의 차이

둘 다 지도학습이지만 예측하는 값의 형태가 다릅니다.

구분 회귀 분류
예측 대상 연속적인 값 범주(Class)
예시 집값 예측 스팸 여부
결과 35000원 Spam
대표 모델 Linear Regression Logistic Regression, SVM, Tree

예를 들어,

집의 크기 → 집값

은 회귀 문제다.

반면

이메일 내용 → 스팸 / 정상

은 분류 문제다.

5. 이번 수업의 핵심은 “분류”

이번 52일 수업에서 다룬 모델들은 대부분 다음 문제를 해결하기 위한 방법입니다.

주어진 X를 보고 Y라는 Class를 어떻게 예측할 것인가?

이를 수식으로 표현하면

$$ X \rightarrow Y $$

이다.

예를 들어 이진 분류에서는

$$ Y \in {0,1} $$

처럼 두 개의 클래스를 예측한다.

다중 분류에서는

$$ Y \in {1,2,\dots,K} $$

처럼 여러 개의 클래스를 예측할 수 있습니다.

6. 그런데 왜 분류 모델이 여러 개일까?

여기서 중요한 질문이 생깁니다.

분류를 하는 방법이 하나면 안 되는 걸까?

데이터의 형태와 문제의 특성이 서로 다르기 때문에 하나의 모델이 모든 문제에서 가장 좋은 성능을 내기는 어렵습니다.

그래서 여러 가지 접근 방법이 등장합니다.

6.1 확률을 이용하는 방법

Logistic Regression

입력 데이터와 클래스 사이의 관계를 선형식으로 표현한 뒤 Sigmoid 함수를 이용하여 확률로 변환합니다.

X
↓
선형식
↓
Sigmoid
↓
확률
↓
Class

6.2 결정경계를 찾는 방법

SVM

각 클래스를 나누는 결정경계 중에서 Margin이 가장 큰 경계를 찾습니다.

Class A  |  결정경계  |  Class B
          ← Margin →

데이터가 직선으로 분리되지 않는다면 Kernel Trick을 이용하여 비선형 문제를 다룰 수 있습니다.

6.3 확률분포를 이용하는 방법

Naive Bayes

Bayes 정리를 이용하여

$$ P(Y|X) $$

즉, 주어진 데이터가 각 클래스에 속할 확률을 계산합니다.

그리고 각 Feature가 조건부 독립이라는 Naive 가정을 사용하여 계산을 단순화합니다.

6.4 질문을 반복하는 방법

Decision Tree

데이터에 질문을 계속 던지면서 데이터를 나눕니다.

나이 > 30?
├─ Yes → 소득 > 3000?
│         ├─ Yes → Class A
│         └─ No  → Class B
│
└─ No  → Class B

어떤 질문을 먼저 할 것인지를 결정하기 위해 Entropy와 Information Gain 등을 사용합니다.

7. 서로 다른 모델을 하나로 묶을 수도 있다

여기서 또 하나의 아이디어가 나온다.

“그렇다면 여러 모델의 의견을 합치면 더 좋은 결과를 얻을 수 있지 않을까요?”

이것이 앙상블 학습(Ensemble Learning)입니다.

모델 A ─┐
모델 B ─┼→ 결합 → 최종 예측
모델 C ─┘

대표적인 방법은 다음과 같다.

Voting

여러 모델의 예측을 투표로 결합합니다.

Bagging

여러 모델을 서로 다른 데이터 표본으로 학습시키고 결과를 결합합니다.

Random Forest

여러 Decision Tree를 결합합니다.

Boosting

이전 모델이 잘못 예측한 부분을 다음 모델이 보완하면서 모델을 순차적으로 추가합니다.

대표적으로

  • AdaBoost
  • Gradient Boosting

등이 있습니다.

8. 모델을 만들었으면 평가해야 한다

모델을 학습했다고 끝나는 것이 아닙니다.

오히려 중요한 질문은 다음과 같습니다.

“이 모델이 실제로 얼마나 잘하는가?”

분류에서는 예측 결과를 먼저 Confusion Matrix로 정리할 수 있습니다.

실제 Positive 실제 Negative
예측 Positive TP FP
예측 Negative FN TN

여기서 여러 가지 평가 지표를 계산할 수 있습니다.

Accuracy

전체 데이터 중 얼마나 정확하게 맞췄는지 나타냅니다.

$$ Accuracy= \frac{TP+TN} {TP+TN+FP+FN} $$

Precision

Positive라고 예측한 것 중 실제 Positive가 얼마나 되는지를 나타냅니다.

$$ Precision= \frac{TP}{TP+FP} $$

Recall

실제 Positive 중에서 모델이 얼마나 찾아냈는지를 나타냅니다.

$$ Recall= \frac{TP}{TP+FN} $$

F1 Score

Precision과 Recall을 함께 고려하는 지표다.

$$ F1= 2 \frac{Precision\cdot Recall} {Precision+Recall} $$

ROC와 AUC

분류 기준값(Threshold)을 바꾸면서 모델의 성능이 어떻게 변하는지도 살펴볼 수 있습니다.

ROC Curve는

$$ x축=FPR $$

$$ y축=TPR(Recall) $$

로 표현한다.

그리고 ROC Curve 아래의 면적을 AUC라고 한다.

일반적으로 AUC가 1에 가까울수록 분류 성능이 좋다고 볼 수 있습니다.

9. 그래서 전체 수업은 하나의 흐름이다

52일 동안 배운 내용을 단순히 모델 이름으로 외우면 굉장히 복잡하게 느껴진다.

하지만 다음과 같이 연결하면 훨씬 쉽게 이해할 수 있습니다.

                    머신러닝
                       │
                 지도학습
                       │
                 분류 문제
                       │
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
     확률 기반       결정경계        규칙 기반
        │              │              │
   Naive Bayes    Logistic / SVM   Decision Tree
                       │
                  Kernel SVM
        │              │              │
        └──────────────┼──────────────┘
                       ↓
                  모델 평가
                       │
       Accuracy / Precision / Recall
                       │
                  F1 / ROC / AUC
                       │
                       ↓
                 Ensemble Learning
                       │
              ┌────────┴────────┐
              ↓                 ↓
           Bagging           Boosting
              ↓                 ↓
        Random Forest      AdaBoost
                         Gradient Boosting

이 그림이 이번 시리즈 전체를 이해하는 가장 중요한 지도다.

11. 공부할 때 가장 중요한 관점

이번 수업에서 모든 수식을 똑같이 외우려고 하면 오히려 더 어려워진다.

먼저 각 모델이 무엇을 해결하기 위해 등장했는지를 이해하는 것이 중요합니다.

Logistic Regression

분류 문제를 확률로 표현하고 싶습니다.

SVM

클래스를 나누는 가장 좋은 결정경계를 찾고 싶습니다.

Kernel SVM

직선으로 분리할 수 없는 데이터도 분류하고 싶습니다.

Naive Bayes

확률과 Bayes 정리를 이용하여 클래스를 판단하고 싶습니다.

Decision Tree

질문을 반복하면서 데이터를 규칙적으로 나누고 싶습니다.

Random Forest

여러 Tree의 결과를 결합하여 더 안정적인 예측을 만들고 싶습니다.

Boosting

이전 모델이 틀린 부분을 다음 모델이 보완하도록 만들고 싶습니다.

12. 가장 중요한 전체 정리

결국 머신러닝 분류의 핵심은 다음 네 단계로 정리할 수 있습니다.

① 분류
   ↓
어떤 방법으로 Class를 예측할 것인가?

② 학습
   ↓
데이터를 이용하여 모델의 파라미터를 어떻게 찾을 것인가?

③ 평가
   ↓
모델이 얼마나 잘 예측하는가?

④ 개선
   ↓
다른 모델을 사용하거나 여러 모델을 결합하면 더 좋아지는가?

이를 52일 수업의 모델에 연결하면 다음과 같다.

분류 방법
├── Logistic Regression
├── SVM
├── Kernel SVM
├── Naive Bayes
└── Decision Tree

       ↓

모델 평가
├── Accuracy
├── Precision
├── Recall
├── F1
└── ROC / AUC

       ↓

앙상블
├── Voting
├── Bagging
│   └── Random Forest
└── Boosting
    ├── AdaBoost
    └── Gradient Boosting

13. 마무리

처음에는 로지스틱 회귀와 SVM, Naive Bayes, Decision Tree가 서로 완전히 다른 내용처럼 보일 수 있습니다.

하지만 결국 모두 같은 질문에서 출발합니다.

“주어진 데이터를 보고 어떤 Class에 속하는지 어떻게 판단할 것인가?”

각 모델은 이 질문에 서로 다른 방식으로 답합니다.

  • Logistic Regression은 확률을 사용하고,
  • SVM은 Margin과 결정경계를 사용하고,
  • Naive Bayes는 확률분포와 Bayes 정리를 사용하고,
  • Decision Tree는 질문과 분할 규칙을 사용한다.

그리고 모델을 만든 뒤에는

“얼마나 잘 맞추는가?”

를 Accuracy, Precision, Recall, F1, ROC, AUC 등으로 평가한다.

마지막으로 여러 모델을 결합하는 Ensemble Learning을 이용하면 단일 모델의 한계를 보완할 수 있습니다.

따라서 이번 시리즈의 핵심은 모델 이름을 무작정 암기하는 것이 아니라,

$$ \boxed{ \text{분류 방법} \rightarrow \text{학습} \rightarrow \text{평가} \rightarrow \text{앙상블} } $$

이라는 전체 흐름을 이해하는 것입니다.

전체 시리즈 목차

  1. [머신러닝] 분류 모델부터 앙상블까지 — 전체 개념 잡기
  2. [머신러닝] 로지스틱 회귀 — 확률로 분류하기
  3. [머신러닝] SVM과 Kernel — 가장 좋은 결정경계 찾기
