[데이터 처리] 데이터와 특성 중요도

2026년 7월 25일 토요일

들어가며

지금까지의 EDA → 결측치와 이상치 → 데이터 불균형을 보았습니다.

단계주요 내용
EDA탐색적 데이터 분석 · pandas · Matplotlib, seaborn
결측치와 이상치결측치와 이상치 · 대체 · 제거 · 변수화
데이터 불균형데이터 불균형 · Undersampling · Oversampling

이번에는 의사결정나무(Decision Tree) 를 통해 각 특성이 모델 예측에 얼마나 기여하는지를 알아보는 특성 중요도(Feature Importance) 개념과, 모델 성능 개선을 위한 특성 엔지니어링(Feature Engineering) 기법을 정리하였습니다.

1. 의사결정나무로 알아보는 특성 중요도

의사결정나무란?

  • 시각적으로 쉽게 이해할 수 있는 모델
  • 스무고개와 같이 특정 질문을 통해 정답을 찾아가는 모델
  • 분류(Classification) 와 회귀(Regression) 모두 사용 가능

의사결정나무의 구조

  • 특정 질문들을 통해 정답을 찾아가는 모델
  • 최상단 Root Node 에서 마지막 Terminal Node 까지 아래 방향으로 진행
Root Node
  └─ Year < 4.5
       ├─ (True)  → Terminal Node
       └─ (False) → Hits < 117.5
                        ├─ Terminal Node
                        └─ Terminal Node

의사결정나무 - 회귀

  • 회귀를 위한 의사결정나무 모델의 학습 방법과 예측 방법
  • 위에서 아래로 진행될수록 데이터의 구역을 나눔
  • 겹치지 않는 구역(R₁, R₂, R₃ …)으로 데이터를 나눔
  • 특정 구역에 데이터가 있으면 예측값은 해당 구역의 평균값

구역을 나누는 방법 (RSS 기준)

$$RSS = \sum_{i=1}^{n} (y_i - f(x_i))^2$$

  • 좌/우 노드의 RSS 합이 가장 작은 지점에서 분할
    • 이 지점이 전체 RSS를 가장 많이 감소시키는 지점
  • RSS 값이 임계값 이하이거나, 트리의 지정된 깊이까지 반복

의사결정나무 - 분류

  • 구역을 나누는 데 오차제곱합(RSS) 대신 불순도(Impurity) 사용
  • 불순도란 다른 데이터가 섞여 있는 정도

불순도 측정 방법 - 지니 계수 (Gini Impurity)

  • 지니 불순도(Gini Impurity): 선택된 항목이 임의로 잘못 분류될 확률
  • 각 클래스 비율의 제곱합을 1에서 뺀 값

$$Gini\ Impurity = 1 - (yes의\ 확률)^2 - (no의\ 확률)^2$$

예시: 전체 학생 100명 중 대학 졸업 여부(Age >= 25 기준 분할)

구분Yes(졸업)No(미졸업)
Age ≥ 2550명25명
Age < 2515명10명

$$Age \geq 25 의\ Gini\ Impurity = 1 - \left(\frac{50}{75}\right)^2 - \left(\frac{25}{75}\right)^2$$

$$Age < 25 의\ Gini\ Impurity = 1 - \left(\frac{15}{25}\right)^2 - \left(\frac{10}{25}\right)^2$$

의사결정나무와 특성중요도

  • 특성중요도(Feature Importance): 각 특성이 모델의 예측에 기여하는 정도를 나타내는 지표
  • 지니계수를 이용해 특성중요도를 계산
  • 각 특성별 지니 계수 감소량을 통해 특성중요도 파악
    • 특정 특성을 활용해 분할했을 때 불순도가 가장 크게 감소했다는 것
    • → 해당 특성이 데이터를 분류하는 데 가장 큰 차이를 만들었다는 뜻

2. 특성 엔지니어링

특성 엔지니어링이란?

  • 새로운 관측치나 변수를 추가하지 않고도 데이터를 보다 유용하게 만드는 방법
  • 기존 데이터를 활용
  • 데이터를 더 잘 설명하는 특성을 생성해 모델의 성능을 개선

특성 엔지니어링 방법

방법영문설명
스케일링Scaling데이터의 값 범위를 일정한 범위로 조정
비닝Binning수치형 데이터를 구간을 활용해 범주형 데이터로 변경
더미Dummy범주형 데이터를 이진벡터를 활용해 변경

스케일링 (Scaling)

  • 데이터의 값 범위를 일정한 범위로 조정하는 과정
  • 특정 특성 값들이 과도하게 크거나 작아서 발생하는 문제 방지
  • 표준화(Standardization), 정규화(Normalization) 등 다양한 방법 존재

비닝(Binning) & 더미(Dummy)

  • 비닝: 수치형 데이터를 구간을 활용하여 범주형 데이터로 변경
  • 더미: 범주형 데이터를 이진벡터를 활용하여 변경
    • One-hot Encoding

마무리 정리

지금까지의 전체 데이터 전처리 흐름은 다음과 같습니다.

EDA → 결측치와 이상치 → 데이터 불균형 → 특성 중요도

의사결정나무는 RSS(회귀) 또는 지니 불순도(분류)를 기준으로 데이터를 분할하며, 이 과정에서 각 특성이 예측에 기여한 정도를 특성중요도로 파악할 수 있습니다.

이어서 스케일링, 비닝, 더미 변수화 같은 특성 엔지니어링 기법을 통해 모델이 데이터를 더 잘 학습하도록 도울 수 있습니다.
