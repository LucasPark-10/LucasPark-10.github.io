[머신러닝 II] 회귀(Regression) 01

2026년 7월 26일 일요일

들어가며

머신러닝의 대표적인 지도학습 알고리즘인 회귀(Regression)에 대해 정리하겠습니다.

회귀 개념, 단순 선형 회귀, 다중 선형 회귀, 다항 회귀, 과적합과 정규화, 회귀 모델 평가 지표까지 순서대로 살펴보겠습니다.

이번 글에서는 회귀 개념, 단순 선형 회귀, 다중 선형 회귀, 다항 회귀를 정리하겠습니다.

1. 회귀 개념

머신러닝의 분야

머신러닝은 크게 아래와 같이 나뉩니다.

  • 지도학습(Supervised Learning): 회귀분석(Regression), 분류(Classification)
  • 비지도학습(Unsupervised Learning): 클러스터링(Clustering), 차원 축소(Dimensionality Reduction)
  • 강화학습(Reinforcement Learning)

지도학습은 컴퓨터에 정답이 있는 데이터를 학습시키는 방법으로, 주어진 입력으로부터 출력 값을 예측하고자 할 때 사용합니다.

회귀분석이란?

회귀분석은 주어진 입력 변수 $X$에 대해 연속적인 출력 변수 $Y$를 예측하는 알고리즘입니다.

즉, 데이터를 가장 잘 설명하는 선을 찾아 입력값에 따른 미래 결과값을 예측하는 알고리즘이라고 할 수 있습니다.

예시 아이스크림 가게를 운영한다고 가정해봅시다.

판매용 아이스크림을 주문할 때 실제 판매량만큼만 주문하고 싶습니다.

이때 평균 기온($X$)을 활용해 미래 판매량($Y$)을 예측할 수 있다면 재고를 효율적으로 관리할 수 있을 것입니다.

  • 데이터: 과거 평균기온($X$)과 그에 따른 아이스크림 판매량($Y$)
  • 가정: 평균 기온과 판매량은 선형적인 관계를 가지고 있음
  • 목표: 평균 기온에 따른 아이스크림 판매량 예측하기
  • 해결 방안: 회귀 분석 알고리즘

회귀식과 손실 함수

회귀분석은 다음과 같은 식으로 표현됩니다.

$$Y \approx \beta_0 + \beta_1 X$$

여기서 $X$는 평균 기온, $Y$는 아이스크림 판매량이며, 데이터를 잘 설명하는 적절한 $\beta_0$(y절편)과 $\beta_1$(기울기)을 찾아야 합니다.

완벽한 예측은 불가능하기 때문에, 실제 값과 예측 값의 차이를 최소한으로 하는 선을 찾아야 합니다.

즉, 손실함수(Loss Function)를 최소로 만드는 $\beta_0$과 $\beta_1$을 찾는 것이 핵심입니다.

  • 손실함수(Loss Function): 예측 값과 실제 값 간의 오차
  • 손실함수를 최소화하기 위한 모델의 인자를 찾는 과정이 필요함

어떻게 최적의 값을 찾을까? - 경사하강법(Gradient Descent)

산 정상을 찾는 과정에 비유할 수 있습니다.

  • 가정: 정상의 위치, 현재 나의 위치와 높이를 알 수 없다. 다만 내 위치에서 일정 수준 이동할 수 있다.
  • 방법: 현재 위치에서 가장 경사가 높은 쪽을 찾아 오르막 방향으로 일정 수준 이동하고, 더 이상 높이 변화가 없을 때까지 반복한다.

회귀에서는 반대로 거꾸로 된 산을 내려가는 방법을 사용합니다.

이를 경사하강법(Gradient Descent)이라 하며, 손실함수를 최소로 만드는 $\beta_0$과 $\beta_1$을 선정하는 데 활용됩니다.

2. 단순 선형 회귀 (Simple Linear Regression)

$$Y \approx \beta_0 + \beta_1 X$$

  • 가장 기본적이고 간단한 방법의 회귀 알고리즘
  • 입력값 $X$와 결과값 $Y$의 관계를 설명할 때 가장 많이 사용되는 단순한 모델
  • 회귀 알고리즘의 기초로, 이를 응용한 다수의 알고리즘이 존재함

특징

  • 가장 기초적이나 여전히 많이 사용되는 알고리즘
  • 입력 값 $X$가 1개인 경우에만 적용 가능
  • 입력 값이 결과 값에 얼마나 영향을 미치는지 알 수 있음
  • 두 변수 간의 관계를 직관적으로 해석하고자 하는 경우 활용

3. 다중 선형회귀와 다항 회귀

다중 선형 회귀 (Multiple Linear Regression)

입력값이 여러 개(2개 이상)인 경우, 즉 여러 개의 입력값 $X_i$로 결과값 $Y$를 예측하고자 하는 경우에 활용하는 회귀 알고리즘입니다.

$$Y \approx \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \ldots + \beta_i X_i$$

  • 입력값 $X$가 여러 개(2개 이상)인 경우 활용할 수 있는 회귀 알고리즘
  • 각 개별 $X_i$에 해당하는 최적의 $\beta_i$를 찾아야 함
  • 예시: 아이스크림 판매량 = $\beta_0$ + $\beta_1$ × 평균 기온 + $\beta_2$ × 강수량

특징

  • 여러 개의 입력 값과 결과 값 간의 관계 확인 가능
  • 어떤 입력 값이 결과값에 어떤 영향을 미치는지 알 수 있음
  • 여러 개의 입력 값 사이 간의 상관관계가 강할 경우 결과에 대한 신뢰성을 잃을 가능성이 있음
    • 상관관계: 두 가지 변수 중 한 변수가 변화하면 다른 한 변수도 따라서 변화하는 관계

다항 회귀 (Polynomial Regression)

다중 선형 회귀 알고리즘 적용 시, 예측 결과값이 좋지 않고 변수들 간의 관계가 선형적이지 않은 경우 다항 회귀(Polynomial Linear Regression)를 사용합니다.

$$Y \approx \beta_0 + \beta_1 X_1 + \beta_2 X_2^2 + \ldots + \beta_i X_i^i$$

  • 1차 함수 선형식으로 표현하기 어려운 분포의 데이터를 위한 회귀
  • 복잡한 분포의 데이터의 경우, 일반 선형회귀 알고리즘 적용 시 낮은 성능의 결과 도출

특징

  • 일차 함수 식으로 표현할 수 없는 복잡한 데이터 분포에도 적용 가능
  • 극단적으로 높은 차수의 모델을 구현할 경우 과적합 현상 발생
    • 과적합: 모델이 과도하게 학습 데이터에 맞춰지는 현상
  • 데이터 관계를 선형으로 표현하기 힘든 경우 사용

회귀 모델 구현하기 (Python)

데이터 분리

import pandas as pd
from sklearn.model_selection import train_test_split

# 데이터셋 불러오기
df = pd.read_csv('data.csv')

train, test = train_test_split(df, test_size=0.2, random_state=21)
  • train_test_split(): 데이터 세트를 분리해주는 함수
    • *arrays: 데이터세트
    • test_size: 테스트세트의 비율 (0~1)
    • random_state: 분할 과정에서의 무작위성 제어

단순/다중 선형 회귀 모델 구현

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

np.random.seed(0)

X = 5 * np.random.rand(100, 1)
y = 3 * X + 5 * np.random.rand(100, 1)

# 데이터 분리
train_X, test_X, train_y, test_y = train_test_split(X, y, test_size=0.3, random_state=0)

simpleLinear = LinearRegression()          # 모델 생성
simpleLinear.fit(train_X, train_y)         # 모델 학습

predicted = simpleLinear.predict(test_X)   # 테스트 데이터에 대한 예측
model_score = simpleLinear.score(test_X, test_y)  # 모델을 평가한 점수 확인

beta_0 = simpleLinear.intercept_   # 학습이 완료된 모델의 beta_0 반환
beta_1 = simpleLinear.coef_        # 학습이 완료된 모델의 beta_1 반환

다항 회귀 모델

# 다항 회귀의 입력값을 변환하기 위한 모듈을 불러옵니다.
from sklearn.preprocessing import PolynomialFeatures

poly_feat = PolynomialFeatures(degree=2, include_bias=True)
poly_X = poly_feat.fit_transform(X)

multilinear = LinearRegression()
multilinear.fit(poly_X, y)
  • 다항 회귀는 먼저 입력 데이터 $X$에 대해 전처리를 진행한 후 다중 선형 회귀를 진행
  • degree: 다항식의 차수
  • include_bias: 편향 변수 추가 여부 (다항식의 모든 거듭제곱이 0일 경우 편향 변수가 추가됨)
  • fit_transform(): $X$와 $X$의 degree 제곱을 추가한 데이터 반환
