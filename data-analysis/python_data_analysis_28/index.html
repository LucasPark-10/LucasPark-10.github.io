[딥러닝 기초] 퍼셉트론(Perceptron)

2026년 7월 31일 금요일

들어가며

이번 글에서는 딥러닝의 가장 기초가 되는 개념인 퍼셉트론에 대해 정리해보겠습니다.

딥러닝이 무엇인지부터 시작해서, 퍼셉트론의 구조와 원리, 그리고 단층 퍼셉트론의 한계와 이를 극복한 다층 퍼셉트론까지 순서대로 살펴보겠습니다.

1. 딥러닝 개론

인공지능, 머신러닝, 딥러닝의 관계

세 개념은 포함 관계로 이해할 수 있습니다.

  • 인공지능(Artificial Intelligence): 가장 큰 범주
    • 머신러닝(Machine Learning): 인공지능을 구현하는 방법론 중 하나
      • 딥러닝(Deep Learning): 머신러닝의 여러 방법론 중 하나

딥러닝의 정의

딥러닝은 인공신경망에 기반하여 컴퓨터에게 사람의 사고방식을 가르치는 방법입니다.

인공 신경망의 정의

인공 신경망은 생물학의 신경망에서 영감을 얻은 학습 알고리즘으로, 사람의 신경 시스템을 모방합니다.

사람의 신경 시스템(Neuron System)은 두뇌의 가장 작은 정보처리 단위인 뉴런(Neuron)으로 구성되어 있으며, 수상돌기(Dendrites), 세포체(Cell Body), 축삭(Axon) 등의 구조를 가지고 있습니다.

인공 신경망의 특징

인공 신경망은 입력층(Input Layer), 은닉층(Hidden Layer), 출력층(Output Layer)으로 구성되며, 모델 스스로 데이터의 특성을 학습합니다.

이러한 특성 덕분에 지도 학습과 비지도 학습 모두에 적용할 수 있으며, 회귀 분석, 분류, 패턴 파악 등 다양한 문제에 활용됩니다.

  • 알파고 제로(AlphaGo Zero)

2. 퍼셉트론(Perceptron)

신경망 이전의 연구

신경망이 등장하기 전에는 얼굴 인식, 숫자 및 문자 인식 등의 문제를 다루려는 연구들이 있었습니다.

명시적 프로그래밍(Explicit Programming)의 한계

과거에는 아래와 같이 if-else 조건문을 통해 규칙을 일일이 명시하는 명시적 프로그래밍 방식이 사용되었습니다.

if () then {
} else if () then {
} else if () then {
} else if () then {} else if () then {}
……

하지만 자율 주행 자동차와 같이 복잡한 문제의 경우, 사람이 일일이 모든 경우의 수를 입력하고 가르치는 것은 불가능에 가깝습니다.

여기서 기계가 스스로 사람처럼 학습할 수 있는 기술의 필요성이 대두되었고, 이러한 필요에서 등장한 것이 1958년의 퍼셉트론입니다.

퍼셉트론의 기본 구조

퍼셉트론은 사람의 신경 세포(뉴런)의 구조를 본떠 만든 초기 형태의 인공 신경망입니다.

$$y = activation(w_0 + w_1x_1 + w_2x_2)$$

변수의미
$x_1, x_2$입력 값
$w_1, w_2$가중치
$B$ (또는 $w_0$)Bias(편향)
$y$출력 값

입력 값들에 각각의 가중치를 곱하여 모두 더한 뒤(Σ), 활성화 함수(Activation function)를 거쳐 최종 출력 값을 얻는 구조입니다.

활성화 함수(Activation Function)

퍼셉트론에서 사용되는 대표적인 활성화 함수는 계단 함수(Step function)입니다.

$$ activation(x) = 1 & x \geq 0 \ 0 & x < 0 $$

퍼셉트론 동작 예시

입력값 $x_1 = 1$(가중치 2), $x_2 = 0$(가중치 1), bias $= -0.5$일 때:

$$y = activation(-0.5 + 1 \cdot 0 + 2 \cdot 1) = activation(1.5) = 1$$

퍼셉트론 코드 예시 (Python)

def perceptron(x, weights):
    # bias
    sum_ = weights[0]
    for i in range(len(x)-1):
        pre_y += weights[i+1] * x[i]
    return 1 if pre_y >= 0 else 0

3. 퍼셉트론 선형 분류기

논리 회로의 역할을 수행하는 퍼셉트론

사람의 신경계와 딥러닝은 다음과 같이 대응됩니다.

  • 사람의 신경계: 뉴런 → 신경망 → 지능
  • 딥러닝: 퍼셉트론 → 인공 신경망 → 인공지능

퍼셉트론은 논리 회로(Logic Gate)의 역할을 수행할 수 있습니다.

논리 회로란 일정한 논리 연산에 의해 출력을 얻는 회로를 의미합니다.

AND gate

A/BC
0/00
1/00
0/10
1/11

퍼셉트론으로 표현하면 다음과 같습니다.

$$C = activation(1 \cdot A + 1 \cdot B - 1.5)$$

OR gate

A/BC
0/00
1/01
0/11
1/11

$$C = activation(1 \cdot A + 1 \cdot B - 0.5)$$

NAND gate (NOT-AND)

A/BC
0/01
1/01
0/11
1/10

$$C = activation((-1) \cdot A + (-1) \cdot B + 1.5)$$

NOR gate (NOT-OR)

A/BC
0/01
1/00
0/10
1/10

$$C = activation((-1) \cdot A + (-1) \cdot B + 0.5)$$

단층 퍼셉트론(Single Layer Perceptron)의 구조

단층 퍼셉트론은 입력층(Input Layer)과 출력층(Output Layer)만으로 이루어져 있습니다.

  • 입력층: 외부로부터 데이터를 입력받는 신경망 입구의 Layer
  • 출력층: 모델의 최종 연산 결과를 내보내는 신경망 출구의 Layer

퍼셉트론을 활용한 선형 분류기

앞서 살펴본 0, 1 데이터를 계산하던 논리 회로 개념을 확장하면, 퍼셉트론을 선형 분류기로 활용해 데이터를 분류할 수 있습니다.

예를 들어 강아지와 고양이 데이터를 하나의 직선으로 구분하는 것이 가능합니다.

4. 비선형적인 문제

하나의 선으로 분류할 수 없는 문제의 등장

모든 데이터가 하나의 직선으로 깔끔하게 분류되는 것은 아닙니다.

데이터의 분포에 따라 하나의 직선으로는 분류할 수 없는 경우가 발생합니다.

비선형적 논리 게이트, XOR gate

A/BC
0/00
1/01
0/11
1/10

XOR(Exclusive OR)은 대표적인 비선형 문제입니다.

좌표평면에 XOR의 출력값을 표시해보면, 하나의 직선만으로는 $C=1$인 점들과 $C=0$인 점들을 완벽히 구분할 수 없습니다.

단층 퍼셉트론으로는 해결 불가능한 XOR gate

이처럼 단층 퍼셉트론은 선형 분류만 가능하기 때문에 XOR 문제를 해결할 수 없습니다.

이 한계는 실제로 1969년 첫 번째 AI 겨울(First AI Winter)을 초래한 주요 원인 중 하나였습니다.

비선형적 접근 방법의 필요성

XOR 문제를 해결하기 위해서는 직선이 아닌 곡선, 혹은 여러 개의 직선을 조합한 비선형적인 접근 방법이 필요합니다.

5. 다층 퍼셉트론

1986년, 첫 번째 빙하기의 끝

XOR 문제로 촉발된 AI 겨울은 1986년 다층 퍼셉트론의 등장과 함께 극복되기 시작했습니다.

비선형적인 문제 해결의 아이디어

단층 퍼셉트론은 입력층과 출력층만 존재하기 때문에 XOR과 같은 비선형 문제를 풀 수 없었습니다.

이를 해결하기 위해 입력층과 출력층 사이에 은닉층(Hidden Layer)을 추가하는 아이디어가 제시되었습니다.

XOR gate 예시로 보는 다층 구조

XOR 연산은 하나의 레이어만으로는 표현이 불가능하지만, NAND 연산과 OR 연산을 함께 사용하면 표현이 가능합니다.

  • 입력층 → 은닉층(NAND Gate, OR Gate) → 출력층(XOR Gate)

이렇게 단층 퍼셉트론을 여러 개 쌓은 구조를 다층 퍼셉트론(Multi Layer Perceptron, MLP)이라고 부릅니다.

은닉층(Hidden Layer)

은닉층이란 입력층과 출력층 사이의 모든 Layer를 의미합니다.

은닉층의 개수와 딥러닝

은닉층이 3층 이상일 경우, 깊은 신경망이라는 의미에서 Deep Learning이라는 용어를 사용합니다.

다층 퍼셉트론이 결정할 수 있는 영역

은닉층의 개수가 늘어날수록 모델이 표현할 수 있는 결정 경계(Decision Boundary)의 형태도 더욱 복잡해집니다.

  • 1 Hidden Layer: 반평면 형태의 단순한 영역 구분 가능
  • 2 Hidden Layers: 볼록한(convex) 다각형 형태의 영역 구분 가능
  • N Hidden Layers: 임의의 복잡한 형태(비볼록 영역 포함)까지 표현 가능

이처럼 은닉층을 깊게 쌓을수록 더 복잡하고 비선형적인 문제를 해결할 수 있게 되며, 이것이 바로 딥러닝이 강력한 성능을 발휘하는 핵심 원리입니다.

마무리 정리

이번 장에서는 딥러닝의 출발점인 퍼셉트론의 개념과 구조, 그리고 이를 활용한 논리 회로 구현과 선형 분류의 원리를 살펴보았습니다.

또한 단층 퍼셉트론이 가진 비선형 문제(XOR)의 한계와, 이를 극복하기 위해 등장한 다층 퍼셉트론(MLP)의 개념까지 정리해보았습니다.
