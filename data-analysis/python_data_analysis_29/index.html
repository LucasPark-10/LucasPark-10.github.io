[딥러닝 기초] 텐서플로우와 딥러닝 학습

2026년 8월 1일 토요일

들어가며

이번 글에서는 딥러닝 모델이 어떻게 학습되는지, 그리고 텐서플로우(TensorFlow)를 활용해 딥러닝 모델을 어떻게 구현하는지 정리해 보겠습니다.

1. 딥러닝 모델의 학습 방법

딥러닝 모델이란

딥러닝 모델은 입력층(Input Layer), 은닉층(Hidden Layer), 출력층(Output Layer)으로 구성된 신경망입니다.

은닉층이 3층 이상일 경우, 깊은 신경망이라는 의미에서 ‘딥러닝(Deep Learning)‘이라는 용어를 사용합니다.

딥러닝 모델의 구성 요소

구성 요소 설명
Node/Unit 각 층을 구성하는 요소
Layer 모델을 구성하는 층
가중치(Weight) 노드 간의 연결 강도

딥러닝 모델의 학습 방법

딥러닝 모델의 학습은 손실 함수(Loss Function)를 최소화하기 위해 최적화(Optimization) 알고리즘을 적용하는 과정입니다.

  • Loss Function: 예측값과 실제값 간의 오차값
  • Optimization: 오차값을 최소화하는 모델의 인자(가중치)를 찾는 것

즉, 예측값과 실제값 간의 오차값을 최소화하기 위해, 오차값을 최소화하는 모델의 인자를 찾는 알고리즘을 적용하는 것이 딥러닝 모델의 학습 방법입니다.

가장 기본적인 최적화 알고리즘, 경사하강법(Gradient Descent, GD)

신경망의 가중치들을 $W$라고 했을 때, 손실함수 $Loss(W)$의 값을 최소화하기 위해 기울기 $\nabla Loss(W)$를 이용하는 방법입니다.

$$W_{t+1} = W_t - \alpha \nabla Loss(W)$$

  • Gradient ($\nabla Loss(W)$): 특정 가중치에서의 기울기
  • 학습률(Learning Rate, $\alpha$): 가중치를 업데이트하는 보폭의 크기

각 가중치들의 기울기를 구하는 방법 : 역전파(Backpropagation)

딥러닝에서는 역전파(Backpropagation)를 통해 각 가중치들의 기울기를 구할 수 있습니다.

역전파는 나의 목표(target) 값과 실제 모델이 예측한 출력(output) 값이 얼마나 차이나는지 구한 후, 오차값을 다시 뒤로 전파해가며 변수들을 갱신하는 알고리즘입니다.

Boom times의 배경 : 역전파

역전파 알고리즘은 신경망 연구의 역사에서 중요한 전환점이 되었습니다.

  • 1950년: 퍼셉트론(Perceptron) 등장
  • 1973년: 첫 번째 AI 겨울(First AI winter)
  • 1980년: 역전파를 통한 Boom times
  • 1988년: 두 번째 AI 겨울(Second AI winter)
  • 2012년: 딥러닝 혁명(Deep learning revolution)

순전파(Forward Propagation)

순전파는 입력 값을 바탕으로 출력 값을 계산하는 과정입니다.

각 퍼셉트론에서 입력값과 가중치를 곱하고 더한 뒤, 활성화 함수를 거쳐 다음 층으로 전달합니다.

역전파(Backpropagation)

역전파는 순전파의 반대 방향으로 이루어지는 과정입니다.

특정 가중치의 기울기(gradient)를 구하기 위해서는 그 전단의 계산 값이 필요하며, 출력층에서부터 입력층 방향으로 오차를 거슬러 전파하면서 각 가중치의 기울기를 계산합니다.

2. 텐서플로우(TensorFlow)

딥러닝 모델 구현을 위해 학습해야 할 분야

딥러닝 모델을 직접 구현하려면 다음과 같은 다양한 분야를 학습해야 합니다.

  • 파이썬: 딥러닝 모델을 작성하는 언어
  • 하드웨어: 좋은 연산 장치
  • C/C++: 연산 장치를 제어하는 언어

이처럼 배워야 할 것이 매우 많기 때문에, 이를 쉽게 도와주는 프레임워크가 필요합니다.

프레임워크를 통한 딥러닝 모델 구현

Caffe, Chainer, DL4J, Keras, CNTK, MatConvNet, MINERVA, MXNet, Purine, TensorFlow, Theano, Torch 등 다양한 딥러닝 프레임워크가 존재합니다.

프레임워크는 딥러닝 모델의 학습과 추론을 위한 프로그램으로, 딥러닝 모델을 쉽게 구현하고 사용할 수 있게 해줍니다.

프레임워크 선택하기

2019년 기준 Deep Learning Framework의 6개월 성장 지수를 보면 TensorFlow(83점)가 PyTorch(66점), Keras(47점), FastAI(10점)보다 압도적으로 높은 점수를 기록했습니다.

이처럼 가장 많이 사용되고 빠른 성장률을 가진 프레임워크인 TensorFlow(텐서플로우)를 활용합니다.

텐서플로우(TensorFlow)란

텐서플로우는 유연하고, 효율적이며, 확장성 있는 딥러닝 프레임워크입니다.

대형 클러스터 컴퓨터부터 스마트폰까지 다양한 디바이스에서 동작합니다.

텐서(Tensor)

텐서(Tensor)는 다차원 배열(Multidimensional Arrays)로 나타내는 데이터를 의미합니다.

딥러닝에서 텐서는 1차원(1-D Tensor), 2차원(2-D Tensor), 3차원(3-D Tensor) 등 다양한 차원으로 표현될 수 있습니다.

플로우(Flow)

플로우(Flow)는 데이터의 흐름을 의미합니다.

텐서플로우에서 계산은 데이터 플로우 그래프로 수행되며, 그래프를 따라 데이터가 노드(Node)를 거쳐 흘러가면서 계산이 이루어집니다.

텐서 + 플로우

‘텐서플로우’라는 이름은 딥러닝에서 데이터를 의미하는 텐서(Tensor)와, 데이터 플로우 그래프를 따라 연산이 수행되는 형태를 의미하는 플로우(Flow)가 합쳐진 것입니다.

텐서플로우 버전별 특징

텐서플로우 version 1.x

이전 텐서플로우 1.x에서는 계산을 위해 그래프 및 세션(Session) 생성이 필요했습니다.

Variable, Constant, Operation 등을 그래프로 미리 정의한 뒤 세션을 통해 실행하는 방식이었습니다.

텐서플로우 version 2.x

2019년 9월부터 배포된 2.0 버전 이후부터는 즉시 실행(Eager Execution) 기능을 통해 계산 그래프, 세션 생성 없이 바로 실행이 가능해졌습니다.

이로 인해 더욱 직관적인 인터페이스로 사용할 수 있게 되었습니다.

3. 텐서플로우 기초 사용법

텐서 다뤄보기

텐서플로우에서는 다양한 타입의 기본 텐서를 다룰 수 있습니다.

  • Constant Tensor (상수 텐서)
  • Sequence Tensor (시퀀스 텐서)
  • Variable Tensor (변수 텐서)

상수 텐서(Constant Tensor) 

import tensorflow as tf

# 상수형 텐서 생성
tensor_a = tf.constant(value, dtype=None, shape=None, name=None)
  • value: 반환되는 상수값
  • dtype: 반환되는 Tensor 타입
  • shape: Tensor의 차원
  • name: 텐서 이름

다양한 상수 텐서 생성하기 

import tensorflow as tf

# 모든 원소 값이 0인 텐서 생성
tensor_b = tf.zeros(shape, dtype=tf.float32, name=None)

# 모든 원소 값이 1인 텐서 생성
tensor_c = tf.ones(shape, dtype=tf.float32, name=None)

시퀀스 텐서(Sequence Tensor)

tf.linspace는 시작 값에서 끝 값까지 지정한 개수만큼 균등하게 증가하는 텐서를 생성합니다.

import tensorflow as tf

# start에서 stop까지 증가하는 num 개수 데이터를 가진 텐서 생성
tensor_d = tf.linspace(start, stop, num, name=None)
  • start: 시작 값
  • stop: 끝 값
  • num: 생성할 데이터 개수
  • name: 텐서의 이름

tf.range는 시작 값에서 끝 값까지 지정한 증가량만큼 증가하는 텐서를 생성합니다.

import tensorflow as tf

# start에서 limit까지 delta씩 증가하는 데이터를 가진 텐서 생성
tensor_e = tf.range(start, limit, delta, name=None)
  • start: 시작 값
  • limit: 끝 값
  • delta: 증가량
  • name: 텐서의 이름

변수 텐서(Variable Tensor) 

import tensorflow as tf

# 변수형 텐서 생성
tensor_f = tf.Variable(initial_value=None, dtype=None, name=None)
  • initial_value: 초기 값
  • dtype: 반환되는 Tensor 타입
  • name: 텐서의 이름

상수 텐서 생성 및 수식 정의 

import tensorflow as tf

# 상수 텐서 생성
a = tf.constant([1, 0], dtype=tf.float32)

# 수식 정의
def forward(x):
    return W * x + b

정의된 수식을 활용한 연산 

# 텐서 계산 및 출력
output = forward(a)
print(output)

4. 텐서플로우로 딥러닝 모델 구현하기

딥러닝 모델 구현 순서

딥러닝 모델은 다음과 같은 순서로 구현합니다.

  1. 데이터셋 준비하기
  2. 딥러닝 모델 구축하기
  3. 모델 학습시키기
  4. 평가 및 예측하기

1. 데이터셋 준비하기 : Epoch와 Batch

  • Epoch: 한 번의 epoch는 전체 데이터 셋에 대해 한 번 학습을 완료한 상태를 의미합니다.
  • Batch: 나뉘어진 데이터 셋으로, 보통 mini-batch라고 표현합니다. iteration은 epoch를 나누어서 실행하는 횟수를 의미합니다.

예시: 총 데이터가 1,000개이고 Batch size가 100이라면

  • 1 iteration = 100개 데이터에 대해서 학습
  • 1 epoch = 1000 / 100 = 10 iteration

데이터셋 준비하기 코드 예시

data = np.random.sample((100, 2))
labels = np.random.sample((100, 1))

# numpy array로부터 데이터셋 생성
dataset = tf.data.Dataset.from_tensor_slices((data, labels))
dataset = dataset.batch(32)

Dataset API를 사용하여 딥러닝 모델용 데이터 셋을 생성합니다.

2. 딥러닝 모델 구축하기 : 고수준 API 활용 (Keras)

Keras는 텐서플로우의 패키지로 제공되는 고수준 API로, 딥러닝 모델을 간단하고 빠르게 구현할 수 있게 해줍니다.

딥러닝 모델 구축을 위한 Keras 메소드

모델 클래스 객체 생성:

tf.keras.models.Sequential()

모델의 각 Layer 구성:

tf.keras.layers.Dense(units, activation)
  • units: 레이어 안의 Node의 수
  • activation: 적용할 activation 함수 설정

Input Layer의 입력 형태 지정하기

가장 첫 번째 층인 Input Layer는 입력 형태에 대한 정보가 필요하므로, input_shape 또는 input_dim 인자를 설정해야 합니다.

모델 구축하기 코드 예시 (1) : 리스트 방식

model = tf.keras.models.Sequential([
    tf.keras.layers.Dense(10, input_dim=2, activation='sigmoid'),
    tf.keras.layers.Dense(10, activation='sigmoid'),
    tf.keras.layers.Dense(1, activation='sigmoid'),
])

모델에 Layer 추가하기

[model].add(tf.keras.layers.Dense(units, activation))

모델 구축하기 코드 예시 (2) : add() 방식

model = tf.keras.models.Sequential()

model.add(tf.keras.layers.Dense(10, input_dim=2, activation='sigmoid'))
model.add(tf.keras.layers.Dense(10, activation='sigmoid'))
model.add(tf.keras.layers.Dense(1, activation='sigmoid'))

3. 딥러닝 모델 학습시키기 : Keras 메소드

모델 학습 방식을 설정하기 위한 함수

[model].compile(optimizer, loss)
  • optimizer: 모델 학습 최적화 방법
  • loss: 손실 함수 설정

모델을 학습시키기 위한 함수

[model].fit(x, y)
  • x: 학습 데이터
  • y: 학습 데이터의 label

딥러닝 모델 학습시키기 코드 예시

model.compile(loss='mean_squared_error', optimizer='SGD')
model.fit(dataset, epochs=100)

4. 평가 및 예측하기 : Keras 메소드

모델을 평가하기 위한 메소드

[model].evaluate(x, y)
  • x: 테스트 데이터
  • y: 테스트 데이터의 label

모델로 예측을 수행하기 위한 함수

[model].predict(x)
  • x: 예측하고자 하는 데이터

평가 및 예측하기 코드 예시

# 테스트 데이터 준비하기
dataset_test = tf.data.Dataset.from_tensor_slices((data_test, labels_test))
dataset_test = dataset.batch(32)

# 모델 평가 및 예측하기
model.evaluate(dataset_test)
predicted_labels_test = model.predict(data_test)

마무리 정리

이번 글에서는 딥러닝 모델의 학습 원리(손실 함수와 최적화, 순전파와 역전파)부터 텐서플로우의 개념, 그리고 Keras를 활용한 실제 딥러닝 모델 구현 순서(데이터셋 준비 → 모델 구축 → 학습 → 평가 및 예측)까지 정리해 보았습니다.
