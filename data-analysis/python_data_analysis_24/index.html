[머신러닝 II] 회귀(Regression) 02

2026년 7월 27일 월요일

들어가며

저번 글에 이어서 과적합과 정규화, 그리고 회귀 모델 평가 지표까지 정리하겠습니다.

1. 과적합과 정규화

과적합 (Overfitting)

과거 데이터를 학습한 다항 회귀 모델이 새로운 데이터에 대한 예측 결과가 매우 낮다면 과적합이 발생한 것입니다.

모델이 주어진 훈련 데이터에 과도하게 맞춰져 새로운 데이터가 입력되었을 때 잘 예측하지 못하는 현상, 즉 모델이 과도하게 복잡해져 일반성이 떨어진 경우를 의미합니다.

과적합 방지 방법

모델이 실제 데이터에서도 잘 적용될 수 있도록 과적합 방지를 위한 다양한 방법을 사용합니다.

  • 검증 과정(Validation)
  • 정규화(Regularization)

검증 과정

훈련 데이터로 훈련시킨 모델의 일반화 능력을 평가하는 과정으로, 테스트 과정 이전에 진행되는 단계입니다.

훈련 데이터를 이용해 모델 학습 → 검증 데이터를 이용해 모델 평가 → 결과를 바탕으로 다시 모델 학습

홀드아웃 검증(Hold-out Validation): 기본적인 검증 방식으로, 학습에 사용되지 않는 검증 세트를 두어 검증을 진행합니다.

  1. 훈련세트를 학습시켜 모델 생성
  2. 검증세트로 모델의 성능 확인
  3. 모델의 하이퍼파라미터 조정 또는 모델 변경 (하이퍼파라미터: 모델을 구성하진 않지만, 모델의 학습에 관여하는 조정 가능한 값. 예: 학습률)
  4. 기대 성능에 도달할 때까지 위 단계를 반복

교차 검증(Cross Validation): 제한된 데이터 샘플에서 머신러닝 모델을 평가하는 데 사용하는 리샘플링 절차입니다.

학습에 사용된 데이터와 검증 데이터에 대한 모델의 예상 적합도 수준(성능)을 추정하기 위해, 서로 다른 데이터 세트로 여러 번 나눈 뒤 모델을 검증하는 방식입니다.

K-fold 교차 검증

  • 훈련 데이터를 계속 변경하며 모델을 훈련시킴
  • 데이터를 K등분으로 나누고 K번 훈련

검증 순서:

  1. Fold를 나누는 기준인 K를 설정하여 데이터셋을 K개 그룹으로 나눔
  2. K개 중 한 개를 검증용, 나머지 (K-1)개를 훈련용으로 사용
  3. K개 모델의 평균 성능이 최종 모델 성능
from sklearn.model_selection import KFold

kfold = KFold(n_splits=5)  # 교차 검증을 위한 객체 생성

for train_idx, val_idx in kfold.split(train_X):  # train과 test로 분리된 인덱스를 반환
    X_train, X_val = train_X[train_idx], train_X[val_idx]
    y_train, y_val = train_y[train_idx], train_y[val_idx]

    # 동일한 가중치 사용을 위해 각 fold 마다 모델 초기화 하기
    model = LinearRegression()
    model.fit(X_train, y_train)

    # 각 iter 별 모델 평가 점수 측정
    score = model.score(X_val, y_val)
  • n_splits: 분리할 데이터(fold) 개수

2. 정규화를 적용한 회귀

Regularization (정규화)

학습 데이터에만 너무 특화되지 않고 일반화가 가능하도록 일종의 규제를 가하는 기법으로, 모델의 복잡성을 줄여 일반화된 모델을 구현하기 위한 방법입니다.

대표적으로 L1 정규화(Lasso), L2 정규화(Ridge), 엘라스틱 넷(Elastic Net)이 있습니다.

방법 의미
L1 정규화 (Lasso) 정말 중요하지 않은 정보는 아예 무시하도록 하는 방법. 불필요한 정보를 제거하여 모델을 단순화시키고, 중요한 정보에 집중하도록 함. 해석이 쉬운 모델이 필요하거나 일부 특성만 필요할 때 유용
L2 정규화 (Ridge) 가능한 단순하게 문제를 풀도록 하는 방법. 모델이 너무 복잡해지는 것을 방지하고, 새로운 문제에도 잘 대응할 수 있음. 모든 변수를 사용하는 것이 유리하거나 변수 간의 상관관계가 높을 때 유용
엘라스틱 넷 (Elastic Net) 단순하게 문제를 풀되, 정말 중요하지 않은 정보는 무시하도록 하는 방법. Ridge와 Lasso의 장점을 결합. L1과 L2 정규화를 모두 활용하고 싶거나, 어느 쪽이 더 적합한지 모를 때 유용

L1 정규화 (Lasso Regularization)

모델이 과적합되지 않도록 손실함수에 L1 규제를 더하여 페널티를 부과하는 방법입니다.

불필요한 입력 값에 대응되는 $\beta_i$를 정확히 0으로 만들어, 몇 개의 중요한 가중치들만 남게 됩니다.

$$L1 = Loss + \alpha \sum_j |w_j|^1$$

특징

  • 너무 많은 $\beta_i$를 0으로 만들 수 있어 모델의 정확성이 떨어질 수 있음
  • 특성 선택이 필요한 경우 유용
  • 몇 개의 중요 변수만 선택하기 때문에 정보 손실의 가능성이 있음

L2 정규화 (Ridge Regularization)

모델이 과적합되지 않도록 손실함수에 L2 규제를 더하여 페널티를 부과하는 방법입니다.

아주 큰 값이나 작은 값을 가지는 이상치에 대한 $\beta_i$를 0에 가까운 값으로 만들며, L1 정규화에 비해 0으로 수렴하는 가중치의 개수가 적습니다.

$$L2 = Loss + \alpha \sum_j |w_j|^2$$

특징

  • $\beta_i$를 0에 가깝게 만들지만 완전한 0은 아니기 때문에 모델이 여전히 복잡할 수 있음
  • 특성들 간의 강한 상관관계를 가질 때 유용하게 사용됨

Elastic Net Regression

L1 정규화와 L2 정규화 적용 비율을 조정한 회귀입니다.

  • $\alpha$: 정규화 적용 강도, $\alpha$ 값이 높을수록 정규화가 강하게 적용됨
  • $\gamma$: L1 정규화 적용 비율 (0 이상 1 이하)

$$Elastic = Loss + \alpha \left( \gamma \sum_j |w_j|^1 + (1-\gamma) \sum_j |w_j|^2 \right)$$

Python 구현

Ridge, Lasso 구현

from sklearn.linear_model import Ridge
from sklearn.linear_model import Lasso

ridge_reg = Ridge(alpha=10)
ridge_reg.fit(train_X, train_y)

lasso_reg = Lasso(alpha=10)
lasso_reg.fit(train_X, train_y)
  • alpha: default는 1이며, 클수록 더 강한 정규화 적용

ElasticNet 구현

from sklearn.linear_model import ElasticNet

ElasticNet_reg = ElasticNet(alpha=0.001, l1_ratio=0.001)
ElasticNet_reg.fit(train_X, train_y)
  • l1_ratio: L1 정규화를 반영할 비율 (0에서 1 사이 값을 가짐)

3. 회귀 알고리즘 평가 지표

어떤 모델이 좋은 모델인지를 평가하려면, 목표를 얼마나 잘 달성했는지 정도를 평가해야 합니다.

회귀 분석 알고리즘의 목표는 실제 값과 모델이 예측하는 값의 차이가 크지 않도록 하는 것입니다.

실제 값과 모델이 예측하는 값의 차이에 기반한 평가 방법으로는 RSS, MSE, MAE, MAPE, $R^2$ 등이 있습니다.

RSS - 단순 오차 (Residual Sum of Squares)

실제 값과 예측 값의 단순 오차 제곱 합입니다.

값이 작을수록 모델의 성능이 높습니다.

$$RSS = \sum (y_i - \hat{y}_i)^2$$

특징

  • 가장 간단한 평가 방법으로 직관적인 해석이 가능
  • 오차를 그대로 이용하기 때문에 입력 값의 크기에 의존적 → 이상치에 민감

MSE - 평균 제곱 오차 (Mean Squared Error)

RSS에서 데이터 수만큼 나눈 값입니다.

값이 작을수록 모델의 성능이 높습니다.

$$MSE = \frac{1}{N} \sum (y_i - \hat{y}_i)^2$$

MAE - 평균 절대값 오차 (Mean Absolute Error)

실제 값과 예측 값의 오차 절대값의 평균입니다.

값이 작을수록 모델의 성능이 높습니다.

$$MAE = \frac{1}{N} \sum |y_i - \hat{y}_i|$$

MSE와 MAE 특징

  • 간단한 평가 방법들로 직관적인 해석이 가능함
  • MSE: 이상치에 민감
  • MAE: 변동성이 큰 지표와 낮은 지표를 같이 예측할 시 유용하며, 이상치에 상대적으로 덜 민감

$R^2$ - 결정계수

모델이 종속 변수의 변동을 얼마나 잘 설명하는지 나타내는 지표로, 1에 가까울수록 높은 성능의 모델입니다.

  • 총 변동(SST, Total Sum of Squares): 관측 값과 평균 간 차이의 제곱합
  • 오차 제곱합(SSE, Sum of Squared Errors): 예측 값과 관측 값 간 차이의 제곱합 (RSS와 같은 지표)

$$R^2 = 1 - \frac{SSE}{SST}$$

특징

  • $R^2$ = 1이면 모델이 데이터를 완벽하게 설명함을 의미
  • $R^2$ = 0이면 모델이 모든 입력에 대해 학습 데이터의 평균값을 예측한다는 의미
  • 위 수식을 통해 도출한 $R^2$는 음수가 될 수도 있으며, 이는 모델이 평균값을 예측하는 것보다도 못한 예측을 한다는 의미
  • 백분율로 표현하기 때문에 데이터의 크기에 의존적이지 않다는 장점이 있지만, 총 변동이 0일 경우 계산할 수 없다는 단점이 있음

회귀 모델 평가 지표 구현 (Python) 

from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 검증 데이터에 대한 예측
y_pred = model.predict(X_valid)

# MSE 계산
mse = mean_squared_error(y_valid, y_pred)
print("Mean Squared Error (MSE):", mse)

# MAE 계산
mae = mean_absolute_error(y_valid, y_pred)
print("Mean Absolute Error (MAE):", mae)

# R-squared 계산
r_squared = r2_score(y_valid, y_pred)
print("R-squared:", r_squared)
  • RSS의 경우 직접 계산하는 방식으로 구현 가능
  • MSE, MAE, R-Squared는 sklearn.metrics를 이용해 구할 수 있음
  • 실제값과 예측값을 전달하여 확인할 수 있음
