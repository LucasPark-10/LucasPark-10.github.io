[PyTorch] 기본 문법 정리

2026년 8월 3일 월요일

들어가며

이번 글에서는 PyTorch의 기본 문법에 대해 정리해보겠습니다.

PyTorch가 무엇인지부터 시작해서, 데이터를 다루는 핵심 개념들, 그리고 Tensor의 생성과 연산, 마지막으로 자동 미분 기능인 Autograd까지 순서대로 살펴보겠습니다.

1. 딥러닝 프레임워크란

딥러닝 모델을 처음부터 직접 구현하려면 행렬, 선형대수학 등 수학에 대한 깊은 이해가 필요합니다.

하지만 딥러닝 프레임워크를 활용하면 수학에 대한 깊은 지식이 없어도 딥러닝 모델을 구현할 수 있습니다.

딥러닝 프레임워크는 딥러닝 학습의 전 과정을 쉽게 진행할 수 있도록 다양한 도구를 제공해줍니다.

2. PyTorch 소개

PyTorch는 Torch 기반의 오픈소스 머신러닝 라이브러리로, 컴퓨터 비전과 자연어 처리 분야에서 유용하게 사용됩니다.

  • Meta의 AI 연구소에서 Torch 라이브러리를 파이썬 기반으로 개발하여 PyTorch라는 이름이 붙었습니다.
  • 연구 분야에서 거의 80% 이상의 논문이 PyTorch를 사용하고 있을 정도로 널리 쓰이고 있습니다.

3. PyTorch 주요 키워드

PyTorch를 학습하기 전에 아래 다섯 가지 핵심 키워드를 먼저 알아두면 좋습니다.

키워드설명
Datasets데이터와 그 라벨(존재할 경우)을 담고 있는 개체입니다. 데이터 전처리 로직을 적용할 수 있습니다.
DataLoaders학습 및 테스트 과정에서 Dataset을 순회하면서 데이터를 제공하는 개체입니다. Mini-batch 구성 등 데이터셋에 대한 다양한 로직을 적용할 수 있습니다.
torch.nn딥러닝 모델을 구성하기 위한 여러 레이어가 구현되어 있는 공간입니다. 다양한 레이어를 활용해 딥러닝 모델을 구현할 수 있습니다.
손실 함수Adam, SGD를 비롯한 다양한 손실 함수를 모델 학습에 활용할 수 있습니다. DataLoader와 손실 함수를 바탕으로 모델을 학습시킵니다.
모델 학습위 요소들을 종합하여 실제로 모델을 학습시키는 과정입니다.

이 다섯 가지 개념이 PyTorch로 딥러닝 모델을 만드는 전체 흐름의 뼈대가 된다고 볼 수 있습니다.

4. PyTorch Tensor 기초 문법

4-1. Tensor란

Tensor는 PyTorch에서 데이터를 표현하는 기본 단위이며, 인공신경망 학습의 전 과정에서 필수적으로 사용됩니다.

수학적으로 Tensor는 다차원 배열(n차원 행렬)로 이해할 수 있습니다.

  • 1차원 Tensor: Vector
  • 2차원 Tensor: Matrix
  • n차원 Tensor: nD Tensor

또한 PyTorch에서는 Tensor와 Numpy 배열 간 상호 변환이 가능합니다.

4-2. Tensor와 Numpy의 관계

torch.from_numpy()와 numpy() 메서드를 활용하면 Tensor와 Numpy 배열 간 상호 변환이 가능합니다.

import numpy as np

arr = np.array([[1, 2, 3]])
t = torch.from_numpy(arr)

print("Tensor:", t)
# Tensor: tensor([[1, 2, 3]], dtype=torch.int32)

print("Back to Numpy:", t.numpy())
# Back to Numpy: [[1 2 3]]

여기서 주의할 점은, Tensor와 Numpy 배열이 메모리를 공유한다는 것입니다.

따라서 한쪽에서 값을 변경하면 다른 쪽에도 그 변경 사항이 영향을 줄 수 있으므로 유의해야 합니다.

4-3. Tensor 생성

PyTorch에서 Tensor를 생성하는 방법은 다양합니다.

import torch

# 리스트로부터 생성
t1 = torch.tensor([1.0, 2.0, 3.0])
print("t1:", t1)
# t1: tensor([1., 2., 3.])

# 0으로 채워진 텐서
t2 = torch.zeros((2, 3))
print("t2:", t2)
# t2: tensor([[0., 0., 0.],
#             [0., 0., 0.]])

# 평균 0, 표준편차 1의 정규분포 텐서
t3 = torch.randn((2, 2))
print("t3:", t3)
# t3: tensor([[ 0.6208,  0.0195],
#             [-0.8228, -0.0672]])
  • torch.tensor(): 리스트로부터 Tensor를 직접 생성합니다.
  • torch.zeros() / torch.ones(): 각각 0, 1로 채워진 Tensor를 생성합니다.
  • torch.randn(): 정규분포를 따르는 무작위 값으로 구성된 Tensor를 생성합니다.

4-4. Tensor 속성

Tensor 객체는 3가지 주요 속성을 가집니다.

x = torch.rand((3, 4), dtype=torch.float32, device='cpu')

print("Shape:", x.shape)
# Shape: torch.Size([3, 4])

print("Data type:", x.dtype)
# Data type: torch.float32

print("Device:", x.device)
# Device: cpu

x.to("cuda:0")  # GPU로 이동
  • shape: Tensor의 크기와 차원을 나타냅니다.
  • dtype: Tensor에 저장되는 데이터의 타입을 의미합니다.
  • device: 해당 Tensor가 CPU에 있는지, 혹은 GPU에 있는지를 나타냅니다. PyTorch는 GPU 가속 연산을 지원하므로, GPU를 사용할 수 있는 경우 device 설정은 성능에 매우 중요한 요소입니다.

4-5. Tensor 연산

Tensor는 덧셈, 곱셈, 행렬곱과 같은 수치 연산을 지원합니다.

+, *, @ 연산자나 torch.add(), torch.matmul() 같은 함수를 사용할 수 있습니다.

a = torch.tensor([[1, 2], [3, 4]])
b = torch.tensor([[10, 20], [30, 40]])

# 덧셈, 곱셈, 행렬곱
print("Add:\n", a + b)
# Add:
#  tensor([[11, 22],
#          [33, 44]])

print("Element-wise Multiply:\n", a * b)
# Element-wise Multiply:
#  tensor([[ 10,  40],
#          [ 90, 160]])

print("Matrix Multiply:\n", a @ b)
# Matrix Multiply:
#  tensor([[ 70, 100],
#          [150, 220]])

함수 형태로도 동일한 연산이 가능합니다.

이때 브로드캐스팅이 함께 적용될 수도 있습니다.

a = torch.tensor([[1, 2], [3, 4]])
b = torch.tensor([[10], [20]])

print("Add:\n", torch.add(a, b))
# Add:
#  tensor([[11, 12],
#          [23, 24]])

print("Matmul:\n", torch.matmul(a, b))
# Matmul:
#  tensor([[ 50],
#          [110]])

이 연산들은 역전파 과정을 위한 자동 미분이 가능한 연산 그래프를 형성하게 되며, 이후 모델 학습 시 사용됩니다.

4-6. Tensor 차원

Tensor는 다양한 차원으로 구성되며, 차원을 자유롭게 추가하거나 제거할 수 있습니다.

x = torch.randn(1, 3, 1, 5)
print("Original shape:", x.shape)
# Original shape: torch.Size([1, 3, 1, 5])

# 차원 제거
x_squeezed = x.squeeze()
print("After squeeze:", x_squeezed.shape)
# After squeeze: torch.Size([3, 5])

# 차원 추가
x_unsqueezed = x_squeezed.unsqueeze(0)
print("After unsqueeze:", x_unsqueezed.shape)
# After unsqueeze: torch.Size([1, 3, 5])

# 모양 변경 (reshape)
x_viewed = x.view(-1, 5)  # -1은 크기를 자동 계산
print("After view:", x_viewed.shape)
# After view: torch.Size([3, 5])
  • tensor.shape: 텐서의 모양을 확인합니다.
  • squeeze(): 차원이 1인 부분을 제거합니다.
  • unsqueeze(dim): 특정 위치에 차원을 추가합니다.
  • view(): 텐서의 크기를 재조정합니다.

4-7. Tensor 차원 확장 (브로드캐스팅)

PyTorch는 자동으로 차원을 확장하는 브로드캐스팅을 지원합니다.

이를 활용하면 서로 크기가 다른 일부 Tensor 간에도 연산이 가능합니다.

a = torch.tensor([[1], [2], [3]])  # 3x1
b = torch.tensor([40, 50, 60])     # 1x3

# 브로드캐스팅되어 3x3 연산 수행
result = a + b
print("Broadcasted result:\n", result)
# Broadcasted result:
#  tensor([[41, 51, 61],
#          [42, 52, 62],
#          [43, 53, 63]])

5. PyTorch 역전파 연산 (Autograd)

5-1. Autograd란

PyTorch Autograd는 Tensor 연산 과정에서 생성된 연산 그래프를 활용하여 자동으로 역전파 연산과 가중치 업데이트를 수행하는 기능입니다.

  • Tensor는 requires_grad 속성을 가질 수 있습니다.
  • requires_grad가 True로 설정된 Tensor는 연산 기록을 저장하며, 이후 .backward() 호출 시 gradient가 자동으로 계산됩니다.
a = torch.tensor([3.0], requires_grad=True)
b = torch.tensor([2.0], requires_grad=True)

z = a * b + b ** 2  # z = ab + b²
z.backward()

print("dz/da:", a.grad)  # b = 2
print("dz/db:", b.grad)  # a + 2b = 3 + 4 = 7
# dz/da: tensor([2.])
# dz/db: tensor([7.])

5-2. torch.no_grad() 블록

모델 검증과 같이 역전파 연산이 필요 없는 경우, with torch.no_grad() 블록을 통해 연산 기록을 하지 않는 블록을 설정할 수 있습니다.

해당 블록 안에서 새로 생성된 Tensor는 requires_grad 값이 False로 설정됩니다.

x = torch.tensor([5.0], requires_grad=True)

with torch.no_grad():
    y = x ** 2

print("Requires grad?", y.requires_grad)  # False

5-3. 신경망 모델의 requires_grad 속성

신경망 모델의 각 레이어의 가중치는 대부분 requires_grad=True로 설정된 Tensor로 구성됩니다.

import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super(MLP, self).__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(28*28, 128)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(128, 64)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 10)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        x = self.flatten(x)
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.softmax(self.fc3(x))
        return x

model = MLP()

5-4. 신경망 모델의 검증 모드와 학습 모드

모델 검증을 위해 eval() 메서드를 호출하면, 해당 모델 가중치의 requires_grad를 False로 설정하고 Dropout 등 학습 과정에서 사용되는 일부 기능을 비활성화합니다.

# 학습 코드와 같은 for loop에서 각 epoch 마다 실행되는 검증 코드
model.eval()  # 모델을 검증 모드로 설정
val_loss = 0
correct = 0
with torch.no_grad():  # 최적화를 진행하지 않도록 환경 설정
    for images, labels in val_loader:  # DataLoader
        outputs = model(images)  # 모델에 데이터를 입력하고 예측값 도출
        val_loss += criterion(outputs, labels).item()
        pred = outputs.argmax(dim=1, keepdim=True)
        correct += pred.eq(labels.view_as(pred)).sum().item()

반대로 학습 과정에서는 train() 메서드를 호출하여 가중치를 requires_grad=True로 설정하고, Dropout 등 일부 기능을 다시 활성화합니다.

epochs = 10
for epoch in range(epochs):
    model.train()
    for images, labels in train_loader:  # DataLoader
        optimizer.zero_grad()          # 최적화 함수 초기화
        outputs = model(images)        # 모델에 데이터를 입력하고 예측값 도출
        loss = criterion(outputs, labels)  # 모델의 예측값과 참값을 바탕으로 손실(Loss) 계산
        loss.backward()                # 손실 함수의 역전파 연산
        optimizer.step()               # 최적화 함수를 통한 모델 업데이트
