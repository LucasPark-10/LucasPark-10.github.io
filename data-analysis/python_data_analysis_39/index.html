[머신러닝 분류 모델] 모델 평가 - Classification Evaluation

2026년 8월 16일 일요일

좋은 모델을 만드는 것만큼 중요한 것이 모델을 올바르게 평가하는 것입니다.

1. 왜 Accuracy만 보면 안 될까?

예를 들어 데이터가 다음과 같다고 하자.

정상 = 990개
이상 = 10개

모든 데이터를 정상이라고 예측하면 990개를 맞춘다.

$$ Accuracy = 99% $$

겉으로 보면 매우 좋은 모델처럼 보입니다.

하지만 실제 이상 데이터를 하나도 찾지 못했다.

따라서 불균형 데이터에서는 Accuracy 하나만으로 모델을 평가하면 위험하다.

2. Confusion Matrix

이진 분류에서 가장 먼저 알아야 하는 네 가지 결과가 있습니다.

실제 Positive 실제 Negative
예측 Positive TP FP
예측 Negative FN TN

TP

실제 Positive를 Positive라고 예측

TN

실제 Negative를 Negative라고 예측

FP

실제 Negative인데 Positive라고 예측

FN

실제 Positive인데 Negative라고 예측

이 네 가지가 모든 분류 평가 지표의 출발점입니다.

3. Accuracy

$$ Accuracy = \frac{TP+TN}{TP+TN+FP+FN} $$

전체 데이터 중 올바르게 예측한 비율입니다.

4. Precision

$$ Precision = \frac{TP}{TP+FP} $$

질문으로 외우면 쉽습니다.

내가 Positive라고 예측한 것 중 진짜 Positive는 얼마나 되는가?

Precision이 중요하다는 것은 False Positive를 줄이는 것이 중요하다는 뜻입니다.

예:

정상 메일을 스팸으로 분류하면 안 되는 상황

5. Recall

$$ Recall = \frac{TP}{TP+FN} $$

질문:

실제 Positive 중에서 내가 얼마나 찾아냈는가?

Recall은 $TPR$ (True Positive Rate)이라고도 합니다.

Recall이 중요하다는 것은 False Negative를 줄이는 것이 중요하다는 뜻입니다.

예:

실제 환자를 정상이라고 판단하면 안 되는 상황

6. Precision vs Recall

지표 핵심 질문 줄이고 싶은 오류
Precision Positive라고 한 것 중 진짜는? FP
Recall 실제 Positive 중 찾은 것은? FN

따라서 어떤 지표가 중요한지는 문제의 목적에 따라 달라집니다.

7. F1 Score

Precision과 Recall을 하나로 합친 지표다.

$$ F1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall} $$

조화평균이기 때문에 둘 중 하나가 지나치게 낮으면 F1도 낮아진다.

Precision과 Recall의 균형을 평가하고 싶을 때 F1을 사용합니다.

8. ROC Curve

분류 모델은 0/1만 출력하는 것이 아니라 확률 또는 점수를 출력할 수 있습니다.

예:

A → 0.91
B → 0.73
C → 0.41
D → 0.12

여기서 Threshold(임계값) 를 바꾸면 Positive/Negative 판정이 달라집니다.

9. FPR

$$ FPR = \frac{FP}{FP+TN} $$

FPR은 실제 Negative 중에서 Positive로 잘못 판단한 비율입니다.

10. ROC

ROC Curve는 다음을 그린다.

  • $x$축 = $FPR$
  • $y$축 = $TPR$ (Recall)

좋은 모델은 일반적으로

FPR은 낮고 TPR은 높은 방향

을 보입니다.

따라서 ROC 곡선은 왼쪽 위에 가까울수록 좋습니다.

11. AUC

AUC는 ROC 곡선 아래의 면적입니다.

$$ AUC = Area\ Under\ ROC $$

일반적으로

$$ 0 \le AUC \le 1 $$

입니다.

AUC ≈ 1
→ 매우 좋은 분류 성능

AUC ≈ 0.5
→ 랜덤 추측 수준

12. 평가 지표 선택 

불균형 데이터?
   ↓
Accuracy만 보지 않기
   ↓
Precision / Recall / F1 확인
   ↓
Threshold 변화까지 보고 싶다면
   ↓
ROC / AUC 확인

상황별 생각

False Positive가 더 위험하다

→ Precision 중요

False Negative가 더 위험하다

→ Recall 중요

둘 다 중요하다

→ F1 고려

Threshold에 따른 분류 성능을 보고 싶다

→ ROC / AUC 고려

13. 평가의 핵심

모델 평가에서 가장 중요한 것은

“무슨 지표가 가장 높은가?“가 아니라 “이 문제에서 어떤 오류가 더 중요한가?”

입니다.

한 문장 정리

분류 모델은 Accuracy 하나만으로 평가하지 않고 Confusion Matrix를 바탕으로 Precision, Recall, F1, ROC, AUC 등을 문제의 목적에 맞게 선택해야 합니다.
