[PyTorch] MNIST 데이터셋 분류 모델 구현하기

2026년 8월 5일 수요일

들어가며

이번 글에서는 PyTorch를 활용해 MNIST 손글씨 숫자 데이터셋을 분류하는 모델을 구현하는 과정을 정리해 보겠습니다.

전체 과정은 아래와 같은 순서로 진행됩니다.

데이터 탐색 → 데이터 전처리 → 모델 정의 → 학습 → 평가 → 성능 개선

1. MNIST 데이터셋이란?

MNIST는 손글씨 숫자 이미지로 구성된 데이터셋입니다.

손으로 쓴 0~9까지의 숫자를 올바르게 분류하는 것이 목표인 대표적인 이미지 분류 태스크입니다.

2. PyTorch 주요 키워드

본격적으로 구현에 들어가기 전에, PyTorch에서 자주 사용되는 핵심 개념들을 먼저 정리하겠습니다.

  • Datasets: 데이터와 (있는 경우) 그 라벨을 담고 있는 개체이며, 데이터 전처리 로직을 적용할 수 있습니다.
  • DataLoaders: 학습 및 테스트 과정에서 Dataset을 순회하면서 데이터를 제공하는 개체입니다. Mini-batch 구성 등 데이터셋에 대한 다양한 로직을 적용할 수 있습니다.
  • torch.nn: 신경망 모델을 구성하는 모듈입니다.
  • 손실 함수: 모델의 예측값과 실제값의 차이를 계산합니다.
  • 모델 학습: 손실을 최소화하는 방향으로 모델 파라미터를 업데이트하는 과정입니다.

3. 데이터 탐색

MNIST 데이터셋은 PyTorch의 torchvision 라이브러리에서 불러오는 기능을 지원합니다.

MNIST의 경우 PyTorch 자체적으로 학습 데이터셋과 테스트 데이터셋을 별도로 불러올 수 있습니다.

torchvision에서 기본 지원하는 다른 데이터셋 목록은 공식 문서에서 확인할 수 있습니다.

from torchvision.datasets import MNIST
from torchvision.transforms import ToTensor

transform = ToTensor()

# Load datasets
train_dataset = MNIST(root='./data', train=True, download=True, transform=transform)
test_dataset = MNIST(root='./data', train=False, download=True, transform=transform)

4. 데이터 전처리

이미지 데이터는 일렬로 나열된 픽셀 값 배열로 변환되어 모델에 입력됩니다.

실습에서는 PyTorch 모델이 처리할 수 있도록 픽셀 값을 Tensor로 변환하는 전처리만 적용하지만, 필요에 따라 다양한 전처리 기법을 추가로 적용할 수 있습니다.

transform = ToTensor()

train_dataset = MNIST(root='./data', train=True, download=True, transform=transform)
test_dataset = MNIST(root='./data', train=False, download=True, transform=transform)

검증(Validation) 데이터

학습 과정에서는 모델의 성능을 검증하기 위해 학습 데이터의 일부를 검증 데이터로 분리하여 사용합니다.

일반적으로 학습 데이터의 10~20%를 검증 데이터로 활용합니다.

 └── 평가 데이터

MNIST Dataset 분할

PyTorch의 random_split 함수를 활용하면 Dataset을 원하는 비율로 분할할 수 있습니다.

아래 예시에서는 MNIST 학습 데이터셋 6만 개 중 랜덤하게 1만 개를 검증 Dataset으로 분할하여 저장합니다.

from torch.utils.data import random_split

val_size = 10000
train_data, val_data = random_split(train_dataset, [len(train_dataset) - val_size, val_size])

MNIST DataLoader 생성

Dataset을 활용해 학습 과정에서 데이터를 불러올 수 있도록 DataLoader를 생성합니다.

DataLoader는 인자로 입력받은 Dataset에서 mini-batch 단위로 데이터를 순회하며, mini-batch의 크기는 batch_size 인자를 통해 조절할 수 있습니다.

또한 shuffle 인자를 통해 Dataset을 순서대로 순회할지, 랜덤하게 순회할지 결정할 수 있습니다.

학습용 DataLoader를 제외하면 순서대로 순회하는 것이 일반적으로 좋습니다.

from torch.utils.data import DataLoader

# DataLoader 구성
train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
val_loader = DataLoader(val_data, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

Batch size란? 매 기울기 조정에 일부 학습 데이터(mini-batch)를 활용함으로써 학습을 최적화합니다. 한 mini-batch의 크기를 Batch size라고 부릅니다. 대부분의 딥러닝 학습에서 mini-batch 방식을 사용하기 때문에, 보통 batch라는 표현이 엄밀한 의미의 mini-batch를 지칭하는 경우가 많습니다. 이런 이유로 mini-batch size 대신 batch size라는 표현을 주로 사용합니다.

5. 모델 정의

이번 실습에서는 MLP(Multi-Layer Perceptron) 구조의 모델을 정의합니다.

28×28 크기의 이미지를 784차원 벡터로 펼친 뒤, 세 개의 Linear Layer를 거쳐 최종적으로 10개의 클래스(0~9)로 분류합니다.

class MLP(nn.Module):
    def __init__(self):
        super(MLP, self).__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(28*28, 128)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(128, 64)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 10)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        x = self.flatten(x)
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.softmax(self.fc3(x))
        return x

model = MLP()

손실 함수 및 최적화 함수 설정

모델 학습 과정에서 사용할 최적화 함수(optimizer)와 손실 함수(loss)를 설정합니다.

import torch.nn as nn
import torch.optim as optim

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

6. 모델 학습

모델을 MNIST 데이터에 학습시키고, 매 epoch마다 검증 결과를 확인합니다.

학습 및 검증 로직은 직접 작성해야 한다는 점에 유의합니다.

학습 코드

epochs = 10
for epoch in range(epochs):
    model.train()
    for images, labels in train_loader:  # DataLoader
        optimizer.zero_grad()               # 최적화 함수 초기화
        outputs = model(images)             # 모델에 데이터를 입력하고 예측값 도출
        loss = criterion(outputs, labels)   # 모델의 예측값과 참값을 바탕으로 손실(Loss) 계산
        loss.backward()                     # 손실 함수의 역전파 연산
        optimizer.step()                    # 최적화 함수를 통한 모델 업데이트

검증 코드

# 학습 코드와 같은 for loop에서 각 epoch마다 실행되는 검증 코드
model.eval()  # 모델을 검증 모드로 설정
val_loss = 0
correct = 0
with torch.no_grad():  # 최적화를 진행하지 않도록 환경 설정
    for images, labels in val_loader:  # DataLoader
        outputs = model(images)  # 모델에 데이터를 입력하고 예측값 도출
        val_loss += criterion(outputs, labels).item()
        pred = outputs.argmax(dim=1, keepdim=True)
        correct += pred.eq(labels.view_as(pred)).sum().item()

7. 모델 평가

학습을 마쳤다면 최종적으로 테스트 데이터셋에 대한 평가를 진행합니다.

# 모델 평가
model.eval()
test_loss = 0
correct = 0
with torch.no_grad():
    for images, labels in test_loader:
        outputs = model(images)
        test_loss += criterion(outputs, labels).item()
        pred = outputs.argmax(dim=1, keepdim=True)
        correct += pred.eq(labels.view_as(pred)).sum().item()

test_loss /= len(test_loader)
test_acc = correct / len(test_loader.dataset)

8. 성능 개선

학습이 완료된 모델에 대해서는 다음과 같은 방법으로 성능을 추가로 개선해볼 수 있습니다.

  • 러닝 레이트(learning rate), 배치 사이즈(batch size), 에포크(epoch) 수 조정
  • 정규화(Regularization) 적용
  • 데이터 증강(Data Augmentation) 적용
  • 드롭아웃(Dropout) 적용
